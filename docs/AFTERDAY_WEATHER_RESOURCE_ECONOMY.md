# AFTERDAY — 재난의 양면성: 자동 물자·시설 경제 v4.2

> 기획 확정: 2026-11-04 · 기준 문서: [CONCEPT_LOCK.md](CONCEPT_LOCK.md), [AFTERDAY_GAME_DESIGN.md](AFTERDAY_GAME_DESIGN.md)
>
> **PD 목표:** 하늘을 보고 오늘의 생존 결정을 바꾸게 한다. 비가 오면 식수가 찬다. 그러나 비가 오래 오면 천막이 무너진다. 햇빛은 몸을 말리지만 물도 말린다. 한파는 식량을 보존하지만 체력을 뺏는다.
>
> 게임 내 시간: **현실 4시간 = DAY 1일**, 1게임분 = 현실 약 10초(기본 1×). 아래 값은 게임 밸런싱 가정이며 실제 서울 기상 수치가 아니다.

## 1. 서사: '살아남으려면 하늘을 읽어라'

처음 며칠간 생존자는 검은 구름만 보면 천막 안으로 숨는다. **DAY 3** 빗줄기가 쏟아지던 저녁, 탱크가 식수를 하나 더 얻었다. 살아남을 수 있을 것 같다는 희망이 든다. 하지만 **DAY 5**, 금이 간 물탱크로는 빗물을 정수하지 못하고, 뜨거운 낮에는 얼마 안 남은 물이 마르기 시작한다. 비는 식량보다 중요할 수 있지만, 탱크를 먼저 고칠 부품이 없으면 물이 곧 사라진다.

30일을 버티는 생존자는 날씨를 '고통'과 '기회'로 동시에 읽는다. 구름이 몰려오면 탱크를 보수하고, 맑은 날에는 몸을 회복하며, 폭염 전에 식수를 저장하고, 한파 전에 식량을 확보한다. 플레이어의 성장은 레벨이 아니라 **다음 날을 계획하는 기술**이다.

## 2. 날씨별 실제 자원 효과

| 날씨 | 생존에 도움 되는 점 | 위험과 비용 | 플레이어가 할 행동 |
|---|---|---|---|
| 맑음 | 습기가 말라 질병 수치 완화; 기본 건강의 느린 회복 | 노출된 물의 미세 증발 | 탱크·보관함 수리, 체력 회복 |
| 흐림 | 증발과 식량 변질이 거의 없음; 휴식·정비 기회 | 빗물 집수도 없음 | 저장 물량을 확인하고 정비 |
| **폭우** | **정수 가능한 물탱크에 식수 자동 축적** | 천막·저장함 손상, 취약 천막의 질병 위험 | 빗물 정수, 천막 보수 |
| **뇌우** | 폭우보다 빠르게 식수 자동 집수 | 천막·저장함·정수 탱크 마모, 긴급 탐색 위험 | 모으되 폭풍 전후 시설 점검 |
| **폭염** | 젖은 시설과 몸 상태가 마르고 질병 완화 | **저장 식수 증발**, 생존자 갈증 1.38배, 부실 보관함 속 식량 변질 | 비 오기 전에 집수, 저장함 보강 |
| 한파 | 식량이 쉽게 상하지 않음, 증발 거의 없음 | 식량 소모량 1.14배, 취약 탱크 동파로 식수 1개 유실(한파 1회당 1회) | 저장함·탱크 수리, 식량 비축 |
| 토네이도 | 직접적인 생산 이득 없음 — 예측과 사전 준비 자체가 생존 기회 | 건물 영구 파괴, 건강·식량·식수·**물탱크 내구도** 손실 | 대피와 저장품 고정, 이후 탱크 보수 |

**중요:** 날씨마다 무리하게 물자 보상을 지급하지 않는다. 토네이도는 순수한 재난으로 남는다. 반면 폭염·폭우처럼 **서로 다른 조건에서 동일한 자원(식수)이 반대로 움직이는 순환**을 완성한다.

## 3. 수치 계약 (초기 튜닝: 실사용자 지표 미검증)

- 물탱크 정수 식수의 최대 비축: **16개**. 기존 저장 데이터가 이미 16개를 초과한 경우 강제 삭제하지 않음.
- 자동 빗물 정수량: 폭우 **게임 24분당 약 1개**, 뇌우 **게임 15분당 약 1개**. 정수 탱크 상태가 70% 이상인 경우의 근사값.
- **자동 집수 하루 최대 +4개**. 계절·프레임률과 무관하게 게임 DAY 단위로 제한. 수동 빗물 회수 +2개(6게임시간 제한)는 별도로 가능하되 전체 저장 한도 16개는 준수.
- 탱크 상태 **70% 이상:** 수집 효율 100%; **40~69%:** 수집 효율 55%; **40% 미만:** 자동·수동 빗물 정수 불가.
- **폭염 식수 증발:** 탱크 양호 시 게임 20분당 약 1개(기준 0.060×0.85/분), 탱크 40~69%에서는 게임 11~12분당 약 1개, 40% 미만에서는 게임 약 6~7분당 1개. 기존 생존자 수분 상태 소모와 별개.
- 탱크가 **30% 미만이면 누수**로 날씨와 무관하게 물이 더 줄어든다. 시설을 수리해야 수집·저장이 안정된다.
- 식량 보관함 상태가 **60% 미만**이면 폭염/비/뇌우에서 식량이 서서히 변질된다. 시설이 양호하면 직접적인 식량 변질이 없다.
- 한파에 탱크 상태가 40% 미만이면 **해당 한파 사건 ID당 식수 1개 유실**; 같은 한파에서 프레임/재접속 때문에 반복 청구되지 않는다.
- 실제 토네이도 근접 시 탱크 -11%, 직격 시 -24% 추가. 저장된 배경 건물 영구 파괴와 경고 사건당 1회 규칙은 유지.
- 계량은 **게임 시간 1분 고정 스텝**으로 수행하며, 반올림 전의 정수 필터/증발 진행률은 저장해 새로고침 이후에도 정확히 이어진다.
- 모든 자동 효과는 **실제 시뮬레이션 날씨**에서만 작동한다. '날씨 시연' 버튼으로 비를 켜도 식수가 차거나 사라지지 않는다(배경 도시 건물 영구 붕괴 예외는 기존 약속 유지).

## 4. 피드백과 감정의 리듬

'식수 7' 같은 숫자만 표시하면 생존 사건으로 느껴지지 않는다.

- 상단 HUD: 현재 날씨와 **정수 진행률·증발·식량 위험** 1줄. 탱크 파손 시 '자동 정수 불가 / 수리 필요'를 즉시 표시.
- 자원 메뉴: 물잔 수량을 **식수 7/16**처럼 표시, 수리 가능한 정수 탱크 내구도(%)도 함께 표시.
- 생존 일지: 실제로 물이 +1 되거나 날씨로 식량·물이 감소하는 **해당 날씨 사건의 첫 변화**를 기록. 알림창과 사용자 제공 MP3는 기존대로 **사건당 한 번만** 유지한다.
- 실시간 날씨 시연은 경제 시뮬레이션과 분리. 비 시연만 켠 뒤 자동 집수까지 된다고 주장하지 않는다.

## 5. 난이도·검증

**초기 5일 위기:** 시작 식량 6개, 식수 8개. 비가 와도 자동 집수는 탱크 정수 상태·하루 상한에 좌우되고, **식량은 비 때문에 생기지 않는다.** 비를 못 만나거나 탱크가 파손되면 식수도 악화한다.

**숙련자 DAY 30:** 강수 시 식수를 모으고, 폭염의 증발을 막고, 저장 시설이 망가지면 부품을 투자하고, 긴급 탐색을 무분별하게 반복하지 않는 플레이어는 장기 생존 가능성을 확보한다.

검증 대상: 폭우 자동 수집 / 뇌우 자동 수집+피해 / 탱크 결함과 수리 / 폭염 증발 / 보관함 식량 변질 / 한파 동파 1회 / 게임 DAY 집수 상한 / 저장 전후 진행률 / 미리보기 무피해 / 전체 회귀 테스트.

**미검증 항목:** 실제 플레이어의 5일·30일 생존률, 날씨별 실제 시각적 탱크 수위 애니메이션 및 모바일 체감 난이도. 위 수치를 현실 기상 데이터나 이미 검증된 게임 운영 성과로 표현하지 않는다.
