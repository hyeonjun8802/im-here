# AFTERDAY 검은 지도 · 거리감과 지역 퀘스트 (v90)

## 사용자 화면에서 달라진 점

- **근거리 지도**: 생존자 옥상을 중심으로 주택·편의점·약국·온실·정수실·통신실이 밀집한 골목 생활권. 새로운 `regions/near_neighborhood.webp` (1365×910) 사용.
- **원거리 지도**: 교량·강변·도심·산업 시설과 언덕을 포함한 넓은 도시권. 별도의 `regions/far_citywide.webp` (1365×910) 사용. 기존 근거리 지도를 재사용하거나 CSS만 축소하는 방식이 아니다.
- 원거리로 전환하면 장소 아이콘과 옥상 마커를 작게 표시하고, 안개가 해제되는 반경을 줄여 축척 차이를 표현한다. **실제 탐사 이동 시간과 사고 확률은 변경하지 않았다.**
- 원거리의 지역 퀘스트 카드에 해당 지구의 풍경을 함께 표시한다. 배경 원본 `district_center.webp`, `district_industrial.webp`, `district_waterfront.webp`, `district_hillside.webp` 각 1152×648.
- 기존 사진 12종, 금속 프레임, 위치 마커, 원형 상태 배지, 휴대폰 배치 및 생존 자원 규칙은 유지한다.

### 실질적인 진행 및 저장 기준

- `src/explorationQuestRegionsV90.js`가 지역·지구·12개 퀘스트를 데이터로 정의한다. 각 `questId`는 원래 `EXPLORATION_SITES[].id`와 완전히 일치한다.
- 미발견: 목표를 숨기고 다음 단서를 요구한다. 발견·미방문: 조사 가능. 방문·미완료: 재조사 필요. 완료: 후속 단서 기록.
- 기존 `explorationMap.sites[siteId].visits/completed/visibility`에서 상태를 **읽기 전용**으로 계산한다. 추가 저장 키나 중복 퀘스트 보상은 없다.
- 위치 해금은 이전과 같이 근거리 탐사·통신탑 발견·부품 4개 복구·무전기·17번 채널 순서로 결정된다. 원거리 지역 사진을 잠긴 상태에서 미리 보여 주지 않는다.
- 이벤트 행동, 이동 시간, 부상/감염 확률, 아이템 지급, 생존자 판정과 결말 조건은 기존 시스템만 사용한다.
- 12곳이 완료되고 17번 채널이 연결되면 기존 정착/구조 신호 **기록**을 선택한다. 구조가 실제로 도착하거나 게임이 강제로 끝나는 신규 이벤트는 없다.

## 확장할 때의 기준

- **기존 12곳 내 다양한 퀘스트**: 데이터 파일에 퀘스트 목표·안내·지구 풍경을 추가하거나 내용을 수정하면 된다. 추가 자원 없이 방문/완료 등 기존 저장 상태만 재사용한다.
- **13번째 새 지역부터**: `EXPLORATION_SITES`, 저장 마이그레이션, 지도 마커·좌표, 실제 해금·상태 전이, 탐사 보상, 퀘스트·지구 데이터 및 회귀 테스트를 함께 확장해야 한다. 퀘스트 메타데이터를 추가하는 것만으로 신규 지역이 실제 플레이 가능해지는 것은 아니다.
- 추가 지구 풍경은 `public/assets/exploration/regions/`에 두되 원본 12개 장소의 사진이나 사용자가 확정한 프레임을 덮어쓰지 않는다.

## 검수 경계

코드 빌드·자동 테스트에서 이미지 파일의 실제 존재, 12개 퀘스트와 기존 저장·해금 계약, 반응형 CSS 연결을 확인한다. 실제 아이폰과 데스크톱 브라우저에서 위치·색감·안개·크롭을 눈으로 확인하는 시각 QA는 별도이며 통과한 것으로 가정하지 않는다.
