# AFTERDAY v3.5 — 실물 에셋 검토 및 리소스 보정

## 기준
- 수정 베이스: v3.4 소스, 원본 shelter/water/storage GLB.
- 사용자 요청: 게임 오브젝트 재검토, 스크린샷 비교, 디테일 개선.
- 이번 패스는 **대표 3개 GLB**의 형태/재질 및 게임 로딩 정합성을 수정했습니다. 전체 오브젝트의 그래픽 품질을 최종 승인한 단계는 아닙니다.

## 발견한 문제와 조치
| 실제 GLB에서 확인한 문제 | 적용한 변경 | 검증 방법 |
|---|---|---|
| 내부 수면 매트리스 위 넓고 두꺼운 직육면체 이불 | 평상시에는 발치에 작은 이불을 접어 두고, 침대 상면/봉제선을 보이도록 재구성 | GLB 실제 메시 전후 VTK 촬영, 3D 노드 검사 |
| 베개가 직육면체라 돌처럼 보임 | 촘촘한 곡면 메시와 모서리가 완만한 천 형태로 변경 | VTK 2회 반복 캡처, 노드 vertex 검사 |
| 천막 천이 단조로움 | 국소 수선 천 패치 및 매트리스 침구 접합부 보강 | 원본 천막 GLB 전후 렌더 |
| 물탱크 표면 구분 어려움 | 구조를 유지하며 녹 흔적과 검사 표시 추가 | 실물 GLB의 리브/표시 전후 촬영 |
| 보관함의 구성 품목 식별 어려움 | 보급 라벨과 스텐실 표시 추가 | GLB 실제 메시 전후 렌더 |
| 기존 폴백 장식을 GLB 위에 또 붙일 경우 겹침 가능 | 중복 장식 재부착을 하지 않고 필요한 디테일을 GLB에 베이킹 | Three.js GLB 교체 로직 회귀 검사 |

## 변경된 실물 GLB

| 파일 | v3.4 메시 | v3.5 메시 | 비고 |
|---|---:|---:|---|
| `afterday_shelter_pbr.glb` | 75 | 83 | 실제 베개/침대/천막 조형 개선 |
| `afterday_water_tank_pbr.glb` | 48 | 50 | 노후와 검사 표식 추가 |
| `afterday_storage_pbr.glb` | 50 | 52 | 물자 식별 라벨 추가 |

GLB 리소스는 `scripts/build_hero_glb.py`에서 재생성할 수 있으며, 공통 색상·재질 단위의 작은 디테일은 가능한 한 병합했습니다. 기존 `narrow sleeping pallet_41`, `pillow_43`, `folded sleeping blanket_42` 이름/기본 좌표는 보존했습니다.
