# AFTERDAY v5.2 — 사건이 실제로 움직이는 프리미엄 모션 제작

> 2026-11-04. 목표 소비자 가격 **₩56,000 유료 설치 게임**. v5.2는 3D 모션의 1차 개선이며 상용 그래픽 완성을 입증하지 않는다.
> 이전: [v5.0 아트 디렉션](AFTERDAY_PREMIUM_VISUAL_56000KRW.md) · [v5.1 시네마틱](AFTERDAY_PREMIUM_CINEMATIC_V510.md)

## 콘셉트

**생존 사건의 결과가 인벤토리 수치와 화면 자막에 그치지 않고, 한 사람의 행동과 실제 옥상의 재질·물체·움직임으로 보인다.**

공간과 게임 규칙은 변하지 않는다. 서울 폐허의 옥상 하나, 조작 가능한 주인공 하나, 동료는 한 명의 비조작 NPC, GAME DAY = 현실 4시간(1×). 장비가 없으면 텐트·재배물·정수기·무전기는 여전히 표시되지 않는다.

## 실제 구현한 세 장면

### 1. ⛺ 텐트 획득 — 폐허에서 안식처를 만드는 동작

1. 플레이어가 탐색을 선택하고 **실제 확률로 텐트를 획득**한다. 결과·소지품은 기존 생존 로직에서 딱 한 번 확정한다.
2. 원래 텐트 GLB/절차 생성 모델과 침구는 약 **7.4초 설치 과정** 동안 잠시 숨긴다. 완성된 천막이 갑자기 튀어나오지 않도록 한다.
3. 정규 옥상 위치 **(-8, ROOF_Y+0.3, -6)**에서 접힌 캔버스가 3D 메쉬로 펼쳐지고 네 기둥과 상부 지지대가 차츰 선다.
4. 기존 **20본 GLB 생존자가 실제 옥상 내 텐트 위치로 걸어가며** 묶는 동작을 수행한다. 별도 캐릭터/전송/텔레포트 없음. `install_tent`는 비보상 비저장 **시각 활동**이다.
5. 임시 설치 프레임이 끝나면 그 자리에서 기존 **PBR 텐트/침구/일상 수면 애니메이션**이 공개된다. 이후 복귀/새로고침에서는 이미 완성된 텐트가 보이며 설치 과정을 다시 추첨하지 않는다.
6. 카메라를 직접 조작해도 선택 완료나 소지품이 취소되지 않는다. 애니메이션은 계속 진행하지만 시네마틱 카메라 이동만 끊어진다.

### 2. 🚁 구조 헬기 — 비행과 보급물의 물리적 연결

1. 실제 라디오 교신에서 **보급 투하 결과가 확정된 후에만** 비행 장면 시작.
2. 기존 헬리콥터에 **회전 블레이드와 반투명 회전 디스크, 깜빡이는 유도등**을 추가한다.
3. 실제 비행 위치에서 **6.3초 시점**에 보급 상자가 분리된다. 기체 아래로 정확히 떨어지는 좌표에서 낙하 시작.
4. 상자와 연결된 **네 개의 로프, 반구형 낙하산, 바람에 따른 낙하 위치 변화**로 옥상 내부에 착지한다. 최종 위치 **(8, ROOF_Y+0.98, 9)**, 건물 옥상의 가드레일 안쪽이다.
5. 낙하하는 보급품의 **그림자 크기와 명도**는 높이에 따라 바뀌며, **14초 부근 착지** 시 낙하산을 내리고 먼지 입자가 퍼진다.
6. 전체 비행·보급 표현은 **18초에 종료**한다. 저장된 교신 뉴스 ID는 다시 재생하지 않는다.
7. 보급품은 기존 `requestRadioContact`가 결정한 **한 번의 보상만 실제 수량에 반영**한다. 상자 착지 시 추가 보급을 만들지 않는다.

### 3. 🌪 토네이도 옥상 접근·직격 — 파편과 충격

1. 풍속 예보/미리보기가 아니라 **실제 옥상 피해 결과가 1회 적용된 경우**에만 새 파편 연출 시작.
2. 토네이도가 실제 지나간 방향에서 부서진 돌·철 조각이 날아와 **한 개의 플레이 옥상** 안에 흩어진다.
3. GPU InstancedMesh로 PC **22개**, 모바일 **10개**의 조각을 일괄 처리한다. 중력으로 낙하해 **ROOF_Y+0.26 이상에서 실제 충돌·감쇠·최대 3회 탄성 반발**을 수행한다.
4. 주인공은 몸을 잠깐 기울이는 **1.65초 이하 충격 반응**을 보이며, 애니메이션이 끝나면 기본 움직임으로 돌아간다. 모바일에서는 조각 수를 줄인다. OS 동작 줄이기를 사용하면 강제 몸 흔들림을 생략한다.
5. 조각은 **6.2초 뒤 사라지며**, 망가진 도시 건물은 **기존 저장 규칙에 따라 계속 영구 파괴** 상태로 남는다.
6. 새 조각은 임시 화면 연출이므로 체력·식량·식수의 피해를 **두 번 차감하지 않으며**, 별도 리스폰/전투/적군/새 맵을 생성하지 않는다.

## 출시 전 남은 기술·아트 과제

- 낙하산 로프 길이·헬기 회전축, 기체 크기와 비행 속도에 대한 실제 카메라별 직접 검수.
- 설치 작업의 발 디딤/주먹 궤적/기둥과 손의 접촉이 자연스러운지 GLB 모션 재촬영 또는 IK 조정.
- 토네이도 파편이 기존 가구/천막·캐릭터와 상호작용하는 **정밀 물리 엔진 충돌**은 아직 구현하지 않았다. 현재는 **옥상 바닥 충돌과 시각 반응만** 처리한다.
- 폭우·야간·주간·저사양 GPU 환경에서 프레임타임/라이트 오버드로/실제 FPS 검증.
- 오디오 리마스터, PBR 소재 재제작, 앱 설치 패키징과 상업용 에셋 라이선스 검증.
