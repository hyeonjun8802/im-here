# AFTERDAY v3.0 — 하루 생활 루틴 구현·검증 기록

## 명세

- **기준 시각:** 한국 표준시(KST), 기존 HUD 및 실제 `Date.now()`과 동일. 서버나 시스템 로캘에 무관하게 +09:00으로 계산.
- **23:00~07:00:** 자동으로 기존 옥상 침대에 이동 → 약 1.45초 자세를 낮추고 옆으로 눕기 → 수면 자세 유지, 기존 GLB 관절을 이용한 호흡 연출.
- **07:00:** 침대에서 약 2.5초에 걸쳐 일어나 침대 앞 안전 지점으로 복귀 → 전망 공간으로 이동 → 16초간 양팔 위로 뻗기·몸 옆으로 기울기·허리 숙이기 등 연속 동작.
- **07:00~09:00:** 기상 후 스트레칭은 서울 달력 기준 하루 한 번. 게임을 새로고침해도 별도 `localStorage` 키 `AFTERDAY_DAILY_CYCLE_V300`에 완료 날짜를 저장하므로 반복되지 않음.
- **그 외 시간:** 기존 `lifePlan.js`의 낮 활동 (요리 준비, 보수, 도시 감상, 기타 등) 그대로.
- **안전:** 폭풍/토네이도에서는 자동 취침·스트레칭보다 대피 동작을 우선. 수동 명령 수행 중 취침 시각에 도달하면 해당 명령 완료 후 자동 취침. 수면 중 수동 행동 시 침대에서 일어나 안전 지점으로 이동한 뒤 목적지로 향함.
- **데이터:** 원래 생존 날짜, 포만감, 수분, 건강, 식량, 날씨 계산 `src/simulation.js`는 변경하지 않음. 수면 루틴은 생존 자원을 임의로 지급하지 않음.
- **프리뷰:** 일상 행동 패널에서 `23시 취침`, `7시 기상·스트레칭`, `실제 시간으로 복귀`. 루틴 동작 시연만 변경하며 게임 날짜 및 생존 데이터는 유지. 재난 시연과 중복되는 경우 안전 행동 우선.

## 개발 파일

- `src/dailyCycle.js`: KST 시각, 루틴 정책, 수면/스트레칭 포즈 보간 수학
- `src/survivorLife.js`: 실제 침대 접근, 수면 상태 유지, 기상과 수동 개입, UI 시연
- `src/characterMotionPlanV190.js`: 기존 캐릭터 관절 기반 스트레칭 키프레임/수면 자세
- `src/beardedSurvivorV190.js`: 실제 활성 GLB를 기존 침대에 눕히는 회전/높이 보정
- `src/main.js`, `index.html`, `src/style.css`: 생활 패널의 테스트 조작과 안내
- `tests/daily-cycle-v300.test.mjs`: 시간 경계, 자정/날짜 전환, 기상 1회, 재난, 모션, 경로, 자원 독립성 검증

## QA 범위 및 한계

- 자동 검증: 기존 174개 + 신규 8개 테스트; 날짜/날씨/생존/공간 배치 기존 소스 체크섬 유지.
- 기존 GLB 원본을 재작성하지 않고 조인트 변형 및 루트 방향만 변경.
- **실제 Chrome WebGL 장면·성능·손발 침대 접촉 세부 품질은 현 실행 환경에서 확인하지 못함.** 실제 게임 화면에서 수면·기상 포즈가 침대와 일치하는지, 텐트에 가려지지 않는지 실기기 시각 검수가 필요.
- 수면 시스템은 **자세 및 루틴 상태 시스템**이며 수면 중 생리 지표 회복이나 스켈레톤 IK/리얼타임 물리 시뮬레이션이 구현됐다는 의미는 아님.
