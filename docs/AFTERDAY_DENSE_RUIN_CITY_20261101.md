# AFTERDAY · 자연에 잠식된 안개 도시 (2026-11-01)

## 아트 목표

참고 이미지: `docs/visual-reference/AFTERDAY_OVERGROWN_CITY_GOAL_20261101.png`.
**주의:** 그림은 목표 콘셉트 이미지이며 실행 게임 스크린샷이 아님. 이미지 자체를 배경 판에 붙이지 않음.

- 옥상 아래 도시의 도로·지면은 **짙은 안개 아래로 소실**. 생존자 옥상 지면은 정상 표시.
- 하나의 플레이어 옥상 밖으로 **가까운 도시 스카이라인에 시각적 밀도** 형성.
- **낡은 외벽, 깨진 창, 불규칙한 붕괴 상단과 지붕 식생**으로 장기간 버려진 인상.
- 멀리 있는 건물도 동일한 날씨, 일몰, 카메라 회전의 **진짜 Three.js 3D 월드**.

## 소스 반영

| 구성요소 | 세부 내용 |
|---|---|
| `src/ruinedBuildingGeometry.js` | 4가지 불규칙한 꼭대기 단면을 가진 3D 폐건물 지오메트리. 벽/옥상 재질 분리, 외부 노멀과 실제 지붕 높이 계산 함수. |
| `src/cityInfillV150.js` | 825개(모바일 329개) 보조 빌딩을 파손 지오메트리 인스턴싱으로 표시하고 파손 지붕 높이에 설비 배치. |
| `src/world.js` | 원경 기본 건물도 동일 파손 지오메트리 기반 폴백 적용; 주인공 옥상과 캐릭터는 변경하지 않음. |
| `src/cityReclamation.js` | GLB·기본·보조 건물에 통합한 균열·외벽 식생·삼각형 수관이 아닌 군집식 수관·줄기·구부러진 철골 5종을 5개 인스턴스 메시로 제공. |
| `src/cityContraction.js` | 고정 건물 좌표를 반경 기준으로 0.83→0.76 압축(최소 166 유지). |
| `src/cityInfillPlanV150.js` | 중앙·중거리·외곽 반경 및 건물 높이 분포 조정(154~735). 기존 건물 개수 유지. |
| `src/groundMist.js` | 기존 깊이 테스트 2~3층 지면 안개를 더욱 밝고 차가운 톤으로 개선. 건물과 옥상의 깊이 관계 유지. |

## 보호 계약

- `src/spatialLayout.js`의 유일한 옥상, `clearZoneRadius=140`, `cityMinRadius=166`, `maxCameraRadius=124` 수정 없음.
- 생존 날짜·시뮬레이션·저장·캐릭터 GLB·기존 GLB/원본 텍스처 및 라이선스 변경 없음.
- 날씨 변화로 건물 배치가 바뀌지 않음.
- 번들 내 `dist`는 Node.js로 실행하는 독립 배포형이며, 브라우저의 `file://` 직접 열기는 지원하지 않음.

## 검증과 미확인 범위

- `npm test`: 총 147개 테스트 통과 (새 지붕의 삼각형 노멀·손상 프로파일·배치 안전성 포함).
- JS 구문 검사와 독립 배포 파일 존재·서버 HTTP 응답 검증.
- Chromium/Xvfb WebGL 렌더 시도가 시간 제한으로 종료됨. **실제 완성 화면, 프레임레이트, Mac/iOS GPU 결과는 확인되지 않음**.
- 원본 GLB 일부는 플랫폼에서 시각적으로 깨끗해 보일 수 있음. 이 수정은 절차적 침식·파손의 통합이며 레퍼런스 이미지 수준의 세밀한 손상 메쉬를 모든 GLB에 손작업으로 새로 조각한 것은 아님.

## 로컬 실행

```
./RUN_STANDALONE_MAC.command
```

브라우저에서 `http://localhost:5173/` 열기. 개발 버전: `npm install && npm run dev`.
