# AFTERDAY v1.0 — Three.js 실시간 날씨 품질 개선 명세

## 이 변경은 실제 게임 렌더링 코드를 수정합니다

이 문서는 이미지 프롬프트나 새 디자인 시안이 아닌 `src/` 내 수정된 Three.js 게임 코드를 설명합니다. 기존 **주인공 단독 옥상 / 멀리 떨어진 3D 서울 폐허 건물 / 실제 날짜 / 생존자 행동 / 깃허브 GLB 로더 / 옥상 전용 GLB 3종**은 유지합니다. 현재 파일에는 별도로 다운로드해야 하는 GitHub SimCity 원본 GLB 83개는 포함되지 않습니다.

### 이전 버전에서 발견한 시각적 한계

1. 비가 모든 거리에 거의 동일한 두께의 밝은 직선(`THREE.LineSegments`)으로 출력되어 원근감이 부족했습니다.
2. 구름은 하늘 정적 텍스처와 단순 스프라이트 위주여서 기상 상태에 따라 구조가 흐르지 않았습니다.
3. 번개는 짧은 1회 섬광 중심이었고 폭우 중 옥상·도시 조명의 연쇄 반응이 제한적이었습니다.
4. 지면 물결은 실제 깊이 구분이 부족했고, 강설은 고정 크기의 점 입자여서 눈송이의 부드러운 가장자리가 없었습니다.
5. 폭풍 중 일사량이 충분히 줄지 않았고, 구름 그림자가 캠프 바닥에 흐르지 않았습니다.
6. 천둥소리는 단일 저주파 사인톤 위주라 번개와의 거리감을 구현하지 못했습니다.

### 실제 3D 원경 규칙 보존

- 주인공이 살고 조작하는 옥상은 원점에 **정확히 하나**입니다.
- 160개(데스크톱) 또는 88개(모바일)의 먼 3D 건물은 고정 좌표를 유지합니다.
- 근경 166~295 / 중경 315~535 / 원경 570~875는 기존 `spatialLayout.js` 규칙을 유지합니다.
- 비/눈/폭염/토네이도를 시연해도 원경 건물의 실제 XYZ는 바뀌지 않습니다.
- `THREE.FogExp2`와 월드 공간의 구름뱅크로 가까운 건물은 일부 보이고 먼 건물은 짙은 안개로 감쇠됩니다.

### 자연스럽게 변화하는 날씨

- `weatherDirector.js`의 지수형 보간값을 그대로 사용합니다. 구름, 강수, 바람, 물기, 강설, 번개가 동일한 실수 상태를 공유합니다.
- 시연 날씨는 **오직 렌더링과 환경음**을 변경합니다. `simulation.js`의 생존 날짜와 게임 날짜를 바꾸지 않습니다.
- 비가 내려야 수면 파동이 보이고, 구름이 많아야 옥상의 그림자와 광량이 변화합니다.
- 강설은 기존 v0.9의 눈 쌓임 오브젝트와 함께 렌더링되며, 기존 거친 점 입자는 숨깁니다.

### 성능 설계

- 비·눈·물결은 `InstancedBufferGeometry + ShaderMaterial`을 사용하여 CPU에서 프레임마다 수천 개 위치 버퍼를 다시 쓰지 않습니다.
- 모바일에서는 인스턴스 수가 자동으로 줄어듭니다. 사용자 화질 설정의 픽셀비/그림자 해상도 최적화는 기존 그대로 유지합니다.
- 기존 선형 빗줄기와 중복 눈 포인트의 렌더링을 비활성화했습니다. 기존 강수 장면 로직은 재난 규칙과의 호환을 위해 보존합니다.
- 셰이더는 화면 품질이 높은 기기 기준으로 설계했으나 실제 스마트폰 GPU에서 성능 측정을 아직 하지 못했습니다.

## 확인할 방법

1. `npm install && npm run download:assets && npm test && npm run dev`를 실행합니다.
2. `http://localhost:5173/?showcase=1`에서 옥상, 건물 원근, 낮/밤 구도가 기존과 동일한지 확인합니다.
3. 우측 날씨 시연 메뉴에서 `폭우` 선택: 비가 카메라 거리마다 다르게 보이는지, 바닥에 수면 물결이 생기는지 확인합니다.
4. `낙뢰` 선택: 번개가 두 차례 펄스처럼 깜빡이고, 옥상/도시 광량이 동기화되는지 확인합니다.
5. `한파·눈` 선택: 각 눈송이가 반투명이고 바람 방향으로 이동하는지, 기존 옥상 적설과 함께 동작하는지 확인합니다.
6. `폭염` 선택: 비·눈의 잔상이 자연스럽게 사라지는지 확인합니다.
7. 데스크톱과 실제 모바일 Safari/Chrome에서 GPU 프로그램 오류와 FPS를 별도로 측정합니다.
8. `npm run qa:visual`을 이용하면 6종 화면 캡처 및 Three.js 실제 draw call 검사를 실행할 수 있습니다. Playwright 추가 설치 및 실행 중인 서버가 필요합니다.

## 정확한 검증 범위

- Node 내장 테스트 **76개 통과**, JavaScript 구문 검사 통과.
- 전용 GLB 3종 파서 감사(`scripts/audit_hero_glb.py`) 통과.
- 네트워크가 차단되어 `three` 및 `vite` 설치·빌드는 이 작업 환경에서 수행하지 못했습니다.
- Chromium은 정책상 실제 사이트/데이터 URL 탐색이 차단되었고, WebGL 셰이더 컴파일/실화면 검증은 미완료입니다.
- **그래픽이 승인된 이미지와 동일하다거나 상용 수준이라고 보증할 수 없습니다.** 차후 실제 캡처와 비교하면서 수치·모델·조명·재질을 보정해야 합니다.
