# AFTERDAY v1.9 캐릭터 개발·디자인 명세

## 1. 목표 아트 콘셉트

고정 디자인: **중년 외국인 남성, 검은 털보, 검은 머리, 갈색 작업용 모자, 눈이 가리지 않는 자연스러운 얼굴, 큰 머리와 둥근 몸통, 짧은 팔다리, 올리브빛 생존복, 작업용 장갑·부츠**. 세계관은 폐허 서울 옥상에서 혼자 살아가는 따뜻하고 실용적인 생존자다. 무기나 슈퍼히어로 장비 없음. 나이 든, 온화하지만 단단한 표정.

- **금지:** 어린 학생 같은 머리색·교복, 일본풍 VRM 교복, 겹치는 눈/눈썹/입술 메시, 심하게 찌그러진 얼굴, 바람에 흩날리는 헤어 액션, 과도한 도형 장비, 실제 게임을 가리는 2D 스프라이트.
- **비율:** 큰 머리+둥근 몸통 > 어깨, 작은 팔/다리; 초장신 캐릭터 금지.
- **기본 시점:** 3D 전방 +Z, Y-up. 360° 모든 방향에서 형태가 유지되어야 함.
- **원본 참조:** `생존_전문가_캐릭터_포즈_시트.png` 첫 칸 및 45°/측면 포즈. 리소스 입력이지 렌더 화면 아님.

## 2. 실구현된 3D GLB

`public/assets/models/afterday/afterday_bearded_survivor_v190.glb`

Trimesh를 사용해 실제 3D 기하를 제작하고 glTF 2.0 GLB로 내보냈다. 약 3.1MB이며 얼굴, 모자, 수염, 조끼·재킷, 장갑·부츠, 배낭 등은 모두 3D 삼각형 메시다. 겹친 평면 스티커/고정된 사진으로 얼굴을 표현하지 않았다. 색은 glTF PBR `baseColorFactor`, roughness/metalness를 구분했다. 텍스처 페인팅 또는 SSS까지 정밀 구현된 모델은 아니다.

### 애니메이션 피벗

- `RigRoot`: 바닥 앵커 및 골반 높이 보정
- `Torso`: 몸통 기울기 및 기타/무전기 소품 연결
- `Head`: 고개 방향과 약한 시선 변화(헤어 바람 없음)
- `UpperArm_L`, `UpperArm_R`: 걷기·도구·식사·무전·기타
- `UpperLeg_L`, `UpperLeg_R`: 보행·착석 상부 다리
- `Knee_L`, `Knee_R`: 무릎 굽힘·발 땅 접촉 보정

이 모델에는 표준 Humanoid `SkinnedMesh`/BlendShape가 없고, 런타임 관절 회전으로 움직인다. 이 기술적 사실을 `SkinnedMesh` 리깅 완료로 표기해서는 안 된다.

## 3. 생활 행동 상태

`life.stage`: `idle` / `approach` / `enter` / `perform` / `exit` / `done`.

| 동작 | 위치 변화 | 모델 행동 |
|---|---|---|
| 걷기 | 기존 옥상 동선 활용 | 양 팔·다리 교차 보행 및 미세 상하 흔들림 |
| 착석 | 의자 앞 진입 후 의자 중심 | 골반 좌표 약 0.40 하강, 양 허벅지 약 -0.94rad, 무릎 +0.70rad |
| 식사 | 식탁의 앉는 장소 | 착석 상태, 손·그릇 동작 |
| 기타 | 모닥불 옆 의자 | 착석, 양팔 연주 자세, 3D 기타 소품 |
| 무전 | 기존 무전기 작업대 | 오른팔 무전 자세, 안테나 소품 |
| 수리 | 작업대 | 상체 전경사, 도구 자세 |
| 감상 | 도시 전망 위치 | 가만히 서서 시선 미세 전환 |
| 대피/휴식 | 기존 게임의 생활 스팟 | 안전 우선 전환 |

기타 음악과 무전음은 기존 오리지널 오디오 구현을 유지. 새 저작권 음악을 추가하지 않음.

## 4. 착석 높이 안전 규칙

이전 v1.7에서 VRM이 허공에 뜬 원인은 의자의 실제 쿠션 높이와 인물의 골반 기준을 따로 계산했기 때문이다. v1.9에서는 공통 값으로 통일했다.

- 의자 원본 위치: `roofY + 0.15`
- 의자 축소 비율: `0.76`
- 쿠션 높이: 원본 `0.91` → `roofY + 0.8416`
- 캐릭터 기본 발 바닥: `roofY + 0.25`
- 캐릭터 기본 골반: `roofY + 0.25 + 1.12 = roofY + 1.37`
- 골반 목표: `roofY + 0.8416 + 0.135 = roofY + 0.9766`
- 루트 목표 이동: `-0.3934`

`seatDrop()` 및 `seatedWeight(life)`는 캐릭터와 의자 높이를 같은 상수에서 가져오며 즉시 순간이동하지 않고 진입·퇴장 시 점진적으로 가중치를 보간한다.

`python3 scripts/verify_seat_geometry_v190.py`는 실제 GLB 삼각형 변환으로 좌석과 골반 차이, 서기·앉기 발바닥 최저높이를 검사한다. **이것은 기하 검증이지 브라우저 3D 동작의 최종 합격이 아니다.**

## 5. 실제 게임에 적용한 점

1. `world.js` 런타임에서 `OfficialVRMAvatarV170` 및 `ReferenceSurvivorV160`의 인스턴스 생성을 제거했다. 기존 인물 표정 레이어도 신규 생성하지 않는다.
2. `BeardedSurvivorV190`가 로컬 GLB를 `GLTFLoader`로 열어 `world.survivor`에 붙인다.
3. 구버전 얼굴·몸체는 모두 숨긴다. 모델 로딩에 실패하면 구버전 일그러진 캐릭터가 재등장하지 않고 오류를 표시한다.
4. 기존 행동·재난·저장·캐릭터 카메라 기능을 유지한다.
5. 독립형 `character.html` 제공. 기존 무거운 원경 도시 로딩과 무관하게 캐릭터의 외형·포즈를 먼저 검증할 수 있다.
6. 캐릭터 GLB는 패키지에 직접 포함돼 외부 무료 아바타 다운로드에 의존하지 않는다.
