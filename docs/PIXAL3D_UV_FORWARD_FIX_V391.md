# Pixal3D v3.9.1 표면·진행축·보행 교정

## 원인

- 4K 베이스 컬러 아틀라스에 매우 작은 UV 섬이 다수 존재했고, 섬 바깥의 검정 픽셀이 WebGL 선형 필터·밉맵에서 경계 안쪽으로 번졌다.
- 그 결과 실제 메시 구멍이 아닌데도 얼굴·모자·의상 전후면에 검은 균열과 투명 구멍처럼 보이는 점이 생겼다.
- Pixal3D 메시의 보이는 정면은 로컬 `-Z`지만 기존 활동 경로는 반대 전방 기준을 사용했다.
- 리타기팅된 Walk/Run 클립은 A-포즈 상완 벌어짐을 그대로 남겼다.

## 수정

- 실제 GLB `TEXCOORD_0` 삼각형을 4096×4096 마스크로 래스터화했다.
- 유효 UV 내부의 고립된 검정 베이크 결함 68,892px을 보간하고 섬 바깥에 최근접 유효색 48px 패딩을 추가했다.
- 기존 검정 수염·머리·장갑은 유효 UV 내부이므로 유지했다.
- 서 있는 이동 및 행동 방향에만 `Math.PI` 전방 보정을 적용했다. GLB 바인드 포즈와 수면 변환은 변경하지 않았다.
- 믹서 평가 뒤 Walk `-0.24rad`, Run `-0.18rad`의 대칭 상완 보정을 적용해 팔을 옆구리 가까이 내렸다.
