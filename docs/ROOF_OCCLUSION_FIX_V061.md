# AFTERDAY v0.6.1 — 거대한 중복 지붕 제거

## 사용자 보고 현상
2026-10-31 화면: 천막과 캠프 바닥 주변에 **넓은 검은 사각 지붕/슬래브가 중복 배치된 것처럼 보이며** 생존 옥상의 일부가 가려짐.

## 코드 조사 결과
- `src/world.js`의 기본 생존 옥상에는 단일 플레이 공간이 정의되어 있음.
- 그러나 `src/artDirection.js`가 `solar-panel-house`(집 형태의 외부 GLB) 및 `ground-cracked`(지면 패치 GLB)를 실제 옥상 내부 소품으로 요청하고 있었음.
- `src/assets.js`의 기존 `instance()`는 GLB를 **Y축 높이만 기준**으로 조정해, 높이가 아주 낮은 원본 모델도 수십 월드 단위의 거대한 가로세로 치수로 커질 수 있었음.
- 스크린샷과 코드가 이 고장 유형에 부합하지만 **검은 판의 정확한 GLB 파일명은 렌더링/모델 원본을 조사하지 못한 환경에서는 확정할 수 없음**.

## 실제 변경
1. 옥상 소품 목록에서 `solar-panel-house`, `ground-cracked` 제거.
2. 기존 `sceneDetails.js`의 3D 태양광 설비와 `world.js`의 균열 바닥을 계속 사용.
3. 외부 GLB에 **최대 가로세로 6.5 월드 단위**의 크기 제한 추가. 높이와 바닥 면적을 동시에 고려해서 정규화.
4. 제한을 초과한 모델은 3D 씬에 추가하지 않도록 런타임 격리.
5. 회귀 테스트 6개 추가. 기존 생존/기상/시간/단일 옥상 규칙 유지.

## 렌더 검수 기준
- 캠프 위의 얇고 넓은 검은 지붕/큰 바닥판이 보이지 않을 것.
- 하나의 지붕 바닥에서 천막·물탱크·모닥불·작업대·식물까지 볼 수 있을 것.
- 천막의 작은 방수포 지붕은 사라지면 안 됨.
- 회전/확대 축소 후에도 중복 바닥판이 생기지 않을 것.
- 로컬 브라우저에서 스크린샷으로 확인할 것.

## 검증 한계
소스 정적 검사와 Node 테스트는 실행 가능. 원본 GLB 다운로드/브라우저 WebGL 렌더링은 현재 샌드박스에서 차단되어 있으므로 **스크린샷과 완전 일치하는 최종 시각 결과는 미검증**.
