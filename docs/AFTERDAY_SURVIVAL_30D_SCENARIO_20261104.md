## 1. 세계와 플레이 원칙

AFTERDAY는 폐허 서울의 고층 건물 **옥상 한 곳**, 성인 생존자 **단 한 명**, 실제 날짜와 밤낮에 연동되는 관찰형 재난 생존 게임이다. 플레이어는 시장이나 군대가 아니다. 물과 식량을 나누고, 강풍 전에 옥상으로 들어올 사람을 대피시키며, 무너진 건물을 바라보는 보호자다. 도시 건설·전투·상점·레벨·일상적인 무한 파밍은 없다.

- 경험 목표: 재난과 생존 70%, 일상 행동 25%, 긴급 자원 탐색 5%.
- **현실 4시간에 게임 하루**가 흐른다(기본 1×, 게임 시계 6배 진행). 활성 플레이 2×는 2시간/일, 4×는 1시간/일이며 오프라인은 기본 1×를 유지한다.
- 메인 목표는 5일의 고비. 도달 가능한 도전 목표는 30일 이상. 30일은 강제 엔딩이 아니며 생존이 계속된다.
- 구 GDD의 기본 모드 사망 지양 제안보다 **이번 사용자의 '진짜 생존 게임' 지시가 우선**한다. 건강 0은 생존 종료이며 기록 초기화는 명시적 버튼으로만 수행한다.
- 초반 2일에는 옥상 직격 없음. 단일 불운으로 즉사하는 대신 누적 대비 실패로 위험해진다.
- 자연재난은 멋진 영상이 아니라 피해 계산, 물자 감소, 시설 손상, 회복 선택, 저장까지 하나의 사건이다.

## 3. 공통 재난 감독 — 6단계

CALM → OMEN → WARNING → IMPACT → AFTERMATH → RECOVERY.

1. **고요함**: 일상 애니메이션과 물자 소모. 현재 비축을 확인한다.
2. **전조**: 구름·바람·강수, HUD에 예정 날씨와 대비 문구가 나온다.
3. **경고**: 각 사건 고유 ID로 알림판과 제공받은 MP3를 한 번만 재생. 닫아도 같은 사건의 로그 변화에 재등장하지 않는다.
4. **충격**: VFX와 실물 게임 데이터가 연동된다. 특히 가까운 토네이도는 식량과 건강을 소모한다.
5. **후유증**: 물자·시설·건강·상황 일지에 실제 결과 저장. 파괴된 도시 건물은 영구 복구 불가.
6. **회복**: 대피소 수리, 치료, 휴식, 실제 강우 중 빗물 정수, 위기시에만 탐색.

## 4. 토네이도: 원거리 / 근접 / 직격

| 사건 | 3D 경로 | 직접 피해 기본값(보호 행동 미실시) |
|---|---|---|
| Distant 원거리 | 무작위 배경 건물 3곳 통과 | 배경 건물 파괴만 |
| Near 근접 | 주변 건물 → 옥상 반경 약 56 월드 단위 → 이탈 | 건강 -13, 식량 -2, 식수 -1, 천막 -12, 보관함 -11 |
| Direct 직격 | 주변 건물 → 옥상 중심 반경 약 18 월드 단위 → 이탈 | 건강 -27, 식량 -4, 식수 -2, 천막 -28, 보관함 -22 |

건물 거리는 게임 월드 단위다. **직격은 회오리 중심이 옥상 지면과 겹칠 정도로 접근하는 연출**이며 주인공의 플레이 공간은 삭제하지 않는다. 주변 건물 붕괴 2–3곳은 그대로 남고 기존 파괴 건물도 유지된다.

**핵심 선택**
- 생존자 대피: 같은 사건의 부상량을 약 69% 낮춘다. 부품 소모 없음. 피해 시각 전에 입력해야 한다.
- 물자 고정: 부품 1개 소모. 식량 유실 약 75% 억제, 식수도 일부 보호. 부상은 막지 못한다.
- 양쪽 대응 가능하지만 시간이 짧다. 알림이 닫혀도 충격 전까지 하단 버튼이 남는다.
- 천막 내구도 45 미만이면 부상 가중. 피해는 사건 ID당 **딱 한 번**만 적용, 저장 및 새로고침 후에도 반복 차감하지 않는다.
- 시작 2일은 원거리만. DAY 3–7의 토네이도 내부 확률은 원거리 44%, 근접 38%, 직격 18%. DAY 8+는 원거리 32%, 근접 40%, 직격 28%.
- 자연 토네이도 발생은 최소 60시간 간격을 두며, 우연성을 매 프레임 굴리지 않는다.
- **날씨 시연**에서 근접/직격 3D 효과를 볼 수 있어도 주인공 식량·건강은 깎지 않는다. 기존 약속에 따라 *배경 건물 파괴는 영구 유지*하는 예외다.

**대표 장면 — DAY 4**
“세 번째 빌딩의 창이 깨지는 순간 바람이 방향을 바꾼다. 물통이 울린다. 남은 식량은 네 개. 밧줄을 매면 밥을 지킬 수 있다. 하지만 천막 안으로 들어가지 않으면 돌조각이 몸에 박힐 것이다.”

## 5. 다른 위기들도 생존 경제에 직결

| 위기 | 감각적 단서 | 실제 손실 또는 기회 | 대응 |
|---|---|---|---|
| 폭염 | 뜨거운 시멘트·사라지는 그늘 | 수분 감소 1.38배, 물 부족 시 건강 감소 | 식수 비축 |
| 폭우 | 빗물·천막 누수·젖은 바닥 | 대피소 상태 악화/질환 위험, 빗물 정수 가능 | 수리, 식수 +2 |
| 뇌우 | 급격한 먹구름·번개·광원 섬광 | 대피소/보관함 손상, 위급 탐색 불가 | 대비와 복구 |
| 한파 | 차가운 새벽·낮은 체온 안정도 | 식량 소모 1.14배, 약한 대피소에서 건강 손실 | 식량 비축, 수리 |
| 동물 | 야간 보관함 주변 그림자 | 식량 1개 손실 가능 | 재고 확보 |
| 침입자 | 계단실 발소리 | 식량 도난, 보관함 내구도 감소 | 부품 1개로 잠금 |
| 질병 | 기침·움직임 저하 | 지속적 건강 하락 | 의약품, 수리와 휴식 |

전투·킬 카운트·적 AI는 없다. 위협은 플레이어의 판단과 비축을 시험한다.

## 6. 생존 경제 — 초기 코드 수치 / 실제 생존률 미검증

| 설정 | 값 | 플레이 의도 |
|---|---|---|
| 초기 능력/물자 | 건강 88, 포만 72, 수분 68 / 식량 6, 물 8, 약 2, 부품 8 | 첫 5일 고비 |
| 포만/수분 자연 소모 | 매분 0.050 / 0.064 | 방치시 빠른 고갈 |
| 위험 구간 | 포만·수분 12 미만 | 지속 건강 손실, 양쪽 낮으면 악화 |
| 휴식 | 건강 +7, 물 부족 시 +2, 최소 4시간 간격 | 클릭 반복 회복 방지 |
| 긴급 탐색 | 부족 시에만, 최소 20시간 간격 | 무한 파밍 방지, 부상 위험 |
| 빗물 회수 | 실제 비/뇌우 중 물 +2, 6시간 간격 | 재난을 기회로 전환 |
| 수리 | 부품 2개 → 가장 약한 시설 +27 | 회복 선택의 비용 |
| 응급치료 | 약 1개 → 건강 +22, 질병 완화 | 한정된 구조자원 |
| 생존 종료 | 건강 0 | 기록 고정, 새 생존 시작을 직접 선택 |

**5일을 넘기기 어렵고 숙련자가 30일을 넘기는 것**은 목표 난이도다. 수치/통계/실사용자 생존률을 확보한 뒤 조정해야 한다. 코드 테스트의 30일 시나리오 성공은 실제 사용자 성적을 뜻하지 않는다.

## 7. 상태·저장·품질 계약

- 경고 고유 키: tornado 사건 번호 / weather 전환 번호 / raider 사건 만료시각 / 이벤트 일지 순번. 이를 저장하므로 재접속해도 같은 경고를 다시 울리지 않는다.
- 생존 종료 이후 자원 증가·치료·탐색 불가. 명시적인 새 생존 버튼과 확인을 거쳐야 저장 기록을 초기화한다.
- 저장 버전 4와 키, 플레이 옥상 1개, 낮/밤, 캐릭터, 날씨 오디오는 그대로 유지한다.
- 기존 사용자 MP3 공지 알림음만 사용. 환경음과 게임 속도는 독립 기능이다.
- 개발 중에는 미리보기 자동 배포를 꺼 두고 **전체 테스트 완료 후 main 배포 1회**만 수행한다.
- 검증 대상: 경고 중복/저장, 근접·직격 피해 1회, 대응 효과, 시연 무피해, 생존 종료, 5일 무대응/30일 관리 전략, 빌드.
- 아직 미완료: 모바일 실기기의 직격 장면 FPS/가독성, 100명 이상 플레이테스트 결과, 선택형 연속 사건 컷신, 서버 시계 인증.

**완료 판정:** 재난 경고 → 대응 가능 → 3D 충격 → 실제 손실 → 기록 → 다음 생존 선택이 연결돼야 한다.


## 2026-11-04 추가 변경 — 4시간 DAY 루프

- **DAY 1 → DAY 2: 실제 4시간**(기본 1×). DAY 5 시작까지 16시간, DAY 30 시작까지 116시간. DAY 30 종료까지 120시간이다.
- 태양·달·수면 루틴·날씨·식수 소비는 동일한 가상 시간 기준으로 계산한다. UI의 DAY는 게임 생성 후 24게임시간 경과를 의미하므로 서울 달력 자정과 다를 수 있다.
- 기존 저장 데이터는 가상 생존일만 연속되도록 마이그레이션하며 식량·체력·파괴 건물은 수정하지 않는다.
- 장기 미접속도 시간은 흐르지만 손실 정산은 최대 8게임시간까지만 적용한다. 이 보호 규칙 때문에 접속 패턴에 따른 난이도 차이가 있을 수 있다.


## 2026-11-04 자원 생존 확장: 비의 선물과 폭염의 대가

[날씨별 물자 경제 상세 문서](AFTERDAY_WEATHER_RESOURCE_ECONOMY.md).

**DAY 3 장면**: 비를 피하던 생존자는 실제 정수 탱크의 식수 수량이 1개 늘어난 것을 발견한다. **DAY 5 장면**: 금이 간 탱크는 비를 받아도 식수로 바꾸지 못한다. 해가 뜨자 수분을 더 마셔야 하고, 탱크의 남은 물도 말라 간다. 마냥 기뻐할 날씨는 없고, 무엇을 먼저 수리할지 결정해야 한다.

폭우·뇌우 자동 집수, 폭염의 저장수 증발, 한파의 식량 보존/탱크 결빙, 맑은 날의 건조·회복은 게임 시계 1분 단위로 정산한다. 물탱크 최대 16개, 자동 집수는 하루 최대 4개. 수치와 5일·30일 생존 난이도는 플레이테스트에서 재조정한다.


## 2026-11-04 최신 시나리오 확정 — 선택을 통해 장비를 획득

이 문서 초기의 DAY 1 '캠프 물자 보유', DAY 3 '정수 탱크 완비', DAY 20 '무전기를 이미 갖고 있다'는 전제를 **새 게임에서는 대체**한다. 최신 본문: [AFTERDAY_ITEM_DISCOVERY_SCENARIO.md](AFTERDAY_ITEM_DISCOVERY_SCENARIO.md). DAY 1에는 텐트 없이 시멘트에서 자며 DAY별 탐색 기회가 생기고 성공할 경우 장비를 하나씩 획득한다. 텐트/정수기/씨앗/무전기는 얻은 경우에만 작동한다. 복구된 옛 저장 데이터에는 기존 장비를 유지한다. 5일 위기와 30일 장기 목표는 유지하되 새 장비 경제의 성공률은 플레이테스트 검증이 필요하다.
