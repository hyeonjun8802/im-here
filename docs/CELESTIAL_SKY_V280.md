# AFTERDAY v2.8 — 시간·날짜 기반 하늘 (2026-11-01)

## 변경 범위

기준: v2.7. 도시 배치/건물 메시, 캐릭터, 생존·기상 시뮬레이션 데이터, 세이브 포맷은 변경하지 않았습니다.

- `src/solar.js`: 기존 서울 태양 고도/방위 계산을 그대로 사용합니다.
- `src/lunar.js`: 서울 위도·경도, 실제 UTC/KST 날짜, 저정밀 월 궤도 계산(고도·방위), 29.530588853일 평균 삭망월 기반 위상을 추가했습니다.
- `src/celestialSky.js`: 2개의 쿼드에 각각 GLSL 태양 원반과 조명된 달 표면을 표현합니다. 달의 반사면은 태양 방향에 따라 초승·반·보름·하현·그믐으로 연속 변화합니다. 구름 밀도, 폭풍, 일출·일몰 경계에 따라 부드럽게 페이드하고 달빛 방향광도 조절됩니다.
- `src/world.js`: 하늘 천체는 프레임마다 실시간 시계에 맞춰 이동하고, 카메라를 회전·줌하면 실제 하늘 방향을 유지하도록 카메라 추적 위치에 업데이트됩니다.
- `src/cinematicWeatherVfx.js`: 움직이는 3D 구름이 태양·달 원반 위에 자연스럽게 겹치도록 렌더 순서만 조정했습니다.
- `index.html`, `src/main.js`, `src/style.css`: 날씨 시연 메뉴에 달 위상 미리보기 4종 버튼을 추가했습니다. 게임 날짜와 저장된 생존 상태는 변경하지 않습니다.

## 사용법

1. Mac: `RUN_STANDALONE_MAC.command` 실행, Chrome/Safari에서 `http://localhost:5173` 접속 (Node.js 필요).
2. 오른쪽 아래 **날씨 시연** → **빛 변화 시연** 슬라이더로 0~24시 태양 이동과 일몰/야간 하늘을 확인합니다.
3. 같은 메뉴의 **달 위상 미리보기** 초승달/반달/보름달/하현달을 누르면 선택한 위상이 보이는 날짜 및 관측 시간대로 **화면만** 전환됩니다.
4. **실제 시간으로 복귀** 버튼으로 현재 KST 시간 및 현재 날짜의 위상으로 되돌립니다.
5. 밤이라고 항상 달이 보이는 것은 아닙니다. 신월에는 원반이 거의 보이지 않고, 다른 날에는 월출·월몰 시간에 따라 지평선 아래에 있을 수 있습니다. 미리보기 버튼을 통해 표시 예시를 확인하세요.

## 구현 정확도와 검증 한계

- 태양: 기존 NOAA 기반 간략 위치 공식; 월출/월몰: 저정밀 근사식. 실제 천문 관측/항법에 사용하지 마세요.
- 달 표면: GPU 절차적 패턴 (달 사진 또는 천체 촬영이 아님). 위상 주기는 평균 삭망월을 사용하여 실제와 몇 시간 차이가 날 수 있습니다.
- 낮→밤 전환은 실시간 시계에 따라 이루어집니다. 별도 백그라운드 지속 작업 없음.
- `npm run check`: 자동 테스트 169/169 통과, 에셋 83/83 존재 확인.
- 독립 실행용 `dist/`에 수정 소스 일치 검증 완료, 로컬 HTTP 서버에서 JS/HTML 200 OK.
- 이 작업 환경의 Chromium/EGL GPU 초기화 실패로 **실제 WebGL 게임 프레임 캡처, 육안 최종 검수 및 FPS 계측은 수행하지 못함**. 예시 그래픽을 실제 게임 캡처로 대체하지 않음.
