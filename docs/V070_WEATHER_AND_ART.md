# AFTERDAY v0.7.0 — 기상·3D 오브젝트 고도화 구현 명세

## 콘셉트 고정
- 주인공이 사는 **옥상 하나만 플레이 가능**. 도시의 나머지 건물은 멀리 있음. 주변 옥상/도시 건설/현대의 정상 작동하는 도로 추가 금지.
- 진짜 3D 입체 객체, 360도 회전, 폐허 서울, 짙은 남색 원경, 황혼의 앰버색 모닥불, 수선된 캔버스 천막, 녹슨 저장 탱크, 배수 시설.
- 소유한 시안 `docs/visual-reference/rooftop_target.png` 및 `docs/visual-reference/weather_target.png`가 색감/구도의 기준.

## 1. 3D 오브젝트 보강 (실제 씬 메쉬)
- 천막: 봉제선/방수 패치, 고정링, 무게추, 로프, 실내 플랩 구조 추가. 단 기존 천막 지붕 실루엣은 유지.
- 물탱크: 지지 프레임 대각 버팀, 수십 개 리벳, 수위 표시기, 배관·필터·밸브, 사다리 추가.
- 보관함: 모서리 금속 보강, 뚜껑 손잡이, 래치 추가.
- 화덕: 돌 테두리, 장작 배치. 배수구/배관 소품 추가.
- 절차 생성 메쉬의 대부분은 원래 형태를 유지하며, 상용 고폴리 GLB가 완성된 것은 아님.

## 2. PBR 계열 텍스처 12종
- 재질 4종: 옥상 콘크리트, 캔버스 천, 산화 아연도금 강재, 재활용 목재.
- 각 재질: 1024×1024 `*_albedo.jpg`, `*_normal.jpg`, `*_roughness.png`.
- 뷰에서 실제 albedo·normal·roughness를 사용하는 Three.js 재질로 연결.
- 콘크리트/천막의 wetness에 따라 roughness/clearcoat/색이 연속적으로 변화.
- 텍스처는 **기존 게임 분위기에 맞춰 알고리즘으로 제작한 근사 파생 맵**. 엄밀한 실측 스캔·고폴리 베이크 품질은 아님.

## 3. 날씨별 연출
- 맑음/흐림: 먼 도시 대기, 하늘 그라데이션, 이동하는 부드러운 구름 스프라이트, 햇빛 방향 변화.
- 폭염: 먼지/대기색 가중 및 강광, 스모그 인상.
- 폭우: 3D 강우 입자, 옥상 3D 링 물결 인스턴싱, 지붕 밖 배수 물줄기, 표면 젖음/광택.
- 낙뢰: 3D 가지 형태의 번개와 장면 조명 플래시, 5초 이상 간격의 낮은 빈도.
- 토네이도: 옥상에서 멀리 발생하는 깔때기 + GPU 포인트 파편, 주변 날씨에 따라 안개·바람 증가.
- 한파: 실제 3D 눈 입자가 천천히 낙하하며 바람에 흔들림.
- 폭우/낙뢰/토네이도는 시연 버튼을 클릭해도 날씨 상태 값을 4.7초 전환 상수로 근접시키므로 **날씨가 한 프레임에 불연속 교체되지 않음**.
- 별도 WebAudio: 비·강풍 노이즈, 번개 저역 천둥 합성, 명시적 클릭 시에만 활성화.

## 4. 객체/상태 호환
- 기존 날짜·세이브·행동·자원·긴급 탐험·동물 경보 코드를 재작성하지 않음.
- 실제 게임 날짜는 `simulation.js`에서 계산, 날씨 패널의 시간/날씨 변경은 시각 시연.
- 단독 옥상 원칙, 지붕 중복 방지 `maxFootprint`와 외부 GLB 격리 코드를 변경하지 않음.

## QA 완료/미완료
- `npm test`: 기존 37개 + 신규 11개 = **48/48 통과**.
- `node --check`: 주요 JavaScript 파일 검사 통과.
- PNG/JPEG 파일 생성/형식 검사 통과, 1024×1024 크기 확인.
- 83개 원본 GitHub GLB는 이 샌드박스에 없어 로컬 실행 시 다운로드 필요.
- Chromium WebGL2 컨텍스트 불가(`webgl2=false`). 따라서 **실제 렌더 결과 시각 비교·FPS·상용 품질은 미검증**.

## Codex 시각 검수 우선순위
1. `?showcase=1`에서 천막 상부에 검은 덮개가 다시 생기지 않는지 확인.
2. 실제 옥상은 하나이며, 이웃 건물이 옥상에 붙어 보이지 않아야 함.
3. 타프 디테일이 떠 있지 않고, 빗물 흐름이 난간 밖으로 내려가는지 확인.
4. 천막 모델/배관 등이 카메라 회전 360도에서 기하학적으로 정상인지 확인.
5. 맑음 → 폭우 → 낙뢰 → 토네이도 → 한파 전환에서 시각적 단절·버벅임이 없어야 함.
6. 보급 자원 소진·휴식·생존자 AI가 계속 작동하고, 날씨 시연이 날짜를 변경하지 않는지 확인.
7. 실제 목표 기기에서 30fps 이상을 기준으로 고사양/저사양 프로파일 측정 후 숫자로 보고.
8. 사용자 제공 콘셉트 이미지와 스크린샷을 좌우 비교하여 부족한 GLB 모델 제작 우선순위를 확정.
