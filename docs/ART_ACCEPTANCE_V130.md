# AFTERDAY v1.3 — 시각 품질 합격 기준

다음 체크 항목은 실제 게임을 실행·캡처한 뒤 확인해야 한다. 현재 패키지에서는 화면 대조가 **미검증**이다.

- [ ] 메인 황혼 카메라에서 주인공 건물 옥상 한 개, 천막, 생존자, 물탱크, 서울 원경이 모두 읽히는가?
- [ ] 인물 확대에서 얼굴이 고무 인형처럼 보이지 않고 복장 레이어·이음매와 장비 고정 관계가 자연스러운가?
- [ ] 캐릭터가 걷거나 앉을 때 스카프/가방/장갑/후드가 관절과 분리되지 않는가?
- [ ] 기타 연주할 때 팔·손·기타 몸체가 서로 겹치거나 뚫리지 않는가?
- [ ] 나무·덩굴이 옥상 바닥을 관통하지 않고, 바람 때 잎과 줄기가 불일치하지 않는가?
- [ ] 가까운 건물 윤곽이 안개 속에서도 읽히고, 중경부터 차츰 흐려지며, 원경은 실루엣으로 남는가?
- [ ] 장마/폭우에서 물줄기, 물웅덩이, 옥상 반사, 라이팅이 함께 변화하는가?
- [ ] 밤 랜턴 bloom이 하늘 전체를 희게 만들거나 UI 텍스트를 흐리지 않는가?
- [ ] 저화질에서도 본 게임이 동작하고, 데스크톱 고화질에서 후처리 기능을 켰을 때 오류가 없는가?
- [ ] 360도 회전했을 때 거대한 중복 지붕이나 납작한 2D 이미지 카드가 나타나지 않는가?
- [ ] 생존 날짜/자원 값이 날씨 시연 이후에도 바뀌지 않는가?
- [ ] 목표 기기에서 30 FPS를 안정적으로 기록하는가? 숫자와 기기 모델을 반드시 기록할 것.

## 디자인 실패 시 우선 조치

1. 개별 오브젝트가 지나치게 '박스'처럼 보이면 GLB 모델의 실루엣·스컬핑을 우선 교체한다.
2. 비가 흰 선처럼 보이면 입자 크기·이동 방향·안개 상호작용을 실제 실행 화면으로 보정한다.
3. 지면이 흰 격자로 보이면 원본 옥상 바닥 텍스처, UV, 톤매핑 설정을 검증한다.
4. 색감이 목표 콘셉트와 다르면 텍스처 그레이딩·노출·거리별 안개부터 수정한다. 건물 위치나 게임 규칙을 변경하지 않는다.
5. 실제 게임 화면을 원본 콘셉트와 나란히 비교한 캡처가 없으면 미완료로 기록한다.
