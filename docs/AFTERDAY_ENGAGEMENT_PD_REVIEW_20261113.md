## 콘셉트 불변 조건

- 한 명의 조작 가능한 생존자, 하나의 옥상, 실제 3D 폐허 도시. 자율행동·재난·복구가 핵심.
- 전투·레벨 파밍·장식 가챠를 추가하여 재미를 억지로 만들지 않는다.
- 압박의 본질은 **정보를 읽고 제한된 물자 중 무엇을 지킬지 선택하는 것**이다.
- 알림 반복, 유료 보상 강요, 로그인을 놓치면 손해 보는 출석·연속접속 압박을 만들지 않는다.

## 한 번의 플레이를 계속할 이유: 3층 루프

1. **짧은 세션(1~3분)**: 생존자 상태 확인 → 가장 급한 위험/기회 한 개 이해 → 실제 선택 → 가시적인 손익 피드백.
2. **하루 루프(운영 1× 기준 10분)**: 날씨 전조 → 대비/절약/탐색 선택 → 시설·건강의 변화 → 다음 준비의 구체적 이유.
3. **30일 장기 루프**: 첫 장비·정수·재배 → 재난 피해와 회복 → 무전·동료 신뢰 → DAY 30의 생존 방식이 기존 선택에 따라 달라지는 결말.

## 장기 스토리 확장안 (이 문서 작성 시점에는 기획, 미구현)

| 기간 | 제목/극적 질문 | 플레이어 선택 | 뒤따르는 실제 결과(구현 시 조건) |
|---|---|---|---|
| DAY 1–5 | **첫 번째 밤** — 살아남으려 내려갈까? | 위험 탐색/정찰/수리재 회수/잔류 | 기존 장비 탐색·건강 변화·노출 수면 위험으로 검증 |
| DAY 6–10 | **비의 값** — 빗물을 믿을 수 있을까? | 물탱크 수리 우선/천막 수리 우선 | 정수량, 비 피해, 회복 비용이 3D와 숫자로 함께 드러나야 함 |
| DAY 11–20 | **끊긴 신호** — 혼자가 아닌가? | 무전 재시도/생존자 구조 허용/물자 우선 | 동료 소비 vs 30% 생산 도움, 저장된 관계 선택으로 후속 대사 변형 |
| DAY 21–29 | **마지막 대비** — 무엇을 남길 것인가? | 대피소·저장고·건강 중 우선 | 재난 복구와 물자 손익으로 선택의 근거를 다시 보여줌 |
| DAY 30+ | **서른 번째 일출** — 생존은 끝인가 시작인가? | 장기 캠프 유지/주변 신호 기다림 | 강제 엔딩·무료 구출 보상 없이 선택에 따른 생존일지와 배경 연출 |

**선택의 기억**이 핵심: 이야기가 '어제 텐트를 잃었는데 오늘도 맑다'처럼 상황을 망각하지 않도록, 기존 상태/선택 결과만 읽어 대사를 변화시킨다. 새 저장 필드는 반드시 마이그레이션 테스트 후 추가한다.

## 이번 1차 안전 개선 — 실제 구현

- `survivalDailyBriefing(day,state)`: 저작된 챕터가 있는 날은 원본 유지, 사이 날짜는 12종의 분위기 비트 순환 + DAY 표시.
- `survivalPriority(state,day)`: 재난, 구조 요청, 식량/식수 부족, 상태 악화, 탐색 기회, 시설·장비 순서로 **실제로 가능한 다음 행동** 안내.
- 기존 `#survival-chapter`에서 하루 한 번 6.5초 표시. 새 고정 UI를 추가하지 않아 모바일의 기존 공간을 침범하지 않음.
- 탐색 행동 완료 뒤 기존 `AfterdayEventBoard`에 `expeditionResult` 사용: 성공/부상/감염/빈손 각각 제목을 다르게 안내, 7.8초 자동 종료·수동 닫기, **silent**.
- 기존 확률, 장비 보상, 날씨, 자원, 저장 스키마, 사운드, 3D 리소스는 변경하지 않음.

## 다음 단계 우선순위

**P1 / 첫 세션 목표 명료화**: 첫 탐색 전 보상·위험의 4개 선택을 체험할 수 있는 30~60초 소프트 튜토리얼. 선택을 강제하지 말고 화면을 가리지 않을 것.

**P1 / 장기 선택 후속 사건**: 기존 동료 구조의 수락·거절, 얻은 장비/부서진 장비를 참고하여 DAY 10·20·30에 서로 다른 **사건과 후속 대사** 구현. 대사만 다른 가짜 선택이 아니라 1개 이상 수치/행동 변화가 있어야 완료로 판정.

**P1 / 회복의 쾌감**: 물탱크 수리, 첫 씨앗 수확, 무전기 획득 후 성공 장면을 명확히 보여주고 한 번만 발생시키며 원치 않는 알림 소리는 추가하지 않음.

**P2 / 일지·회고**: 저장된 '내가 결정한 것 → 실제로 벌어진 일 → 다음 대비'를 새 패널이 아니라 기존 일지/상황 메뉴 안에 요약. 강제 알림/출석은 사용하지 않음.

## 플레이테스트 및 관측

현재 실측 데이터는 없으므로 아래는 성공률 **확정 목표가 아닌 측정 항목**이다.

- 첫 3분: 최초 탐색 제안 노출→열람→4개 선택 중 선택 완료율, 선택까지 걸린 시간, 첫 보상/실패 직후 이탈.
- 첫 생존일: 장비를 한 개 이상 획득한 비율, 과도한 첫날 사망, 빈손 결과 후 재도전·재방문.
- DAY 5/10/20/30 도달률, 날씨 전조 관찰 후 대응률, 재난 후 복구 완료 시간.
- D1/D7 재방문, 1세션 체류시간, 탭 닫기 이유(정량 추정 금지), 3D 로딩 성공률/FPS.
- PC/모바일 별도 분석, 기존 저장 사용자/신규 시작 사용자 분리, 유료 광고가 비정상적인 동기를 만들지 않도록 보상형 광고는 완전 선택형.

## 릴리스 게이트

1. 스토리 메시지가 실제 구현되지 않은 보상·구조·퀘스트를 약속하지 않는지 검수.
2. 기존 시나리오 마일스톤(DAY 2·3·5·7·10·15·20·30) 텍스트 보존.
3. 키트·자원·건강·확률·사망·날씨·저장 로직 불변.
4. 탐색 결과 카드 중복 알림음 없음, 강제 선택 차단 없음, 재난 팝업이 우선.
5. 테스트 통과 후 PC/모바일 **실제 브라우저**에서 이야기와 카드가 가리지 않는지 시각 QA.
6. 운영 지표로 2차 수치 밸런싱을 결정할 것. 자동 테스트 통과만으로 재미를 보장한다고 보고하지 않는다.
