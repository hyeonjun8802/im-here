# AFTERDAY v3.7 — 손에 쥔 도구의 GLB 좌표계 교정

## 문제와 원인
- v3.6은 무전기·식량·물통을 `UpperArm_R`의 로컬 `Y=-1.0` 전후에 배치했습니다.
- 실제 GLB의 `UpperArm_R`/`UpperArm_L`은 바인드 포즈에서 X축으로 180° 회전해 있으며, 손끝은 **로컬 Y=+0.65** 부근에 있습니다. 음수 Y는 어깨/머리 반대편 공간에 소품을 배치합니다.
- 팔 회전의 좌우 부호도 잘못되어 손이 몸 안쪽으로 접근하지 않았습니다.

## 실제 파일 변경
- `src/handAnchors.js` 신규: 원본 9관절 GLB의 오른손/왼손 메시를 기준으로 손목 소켓을 생성. 본 바인드 회전을 반대로 적용해 소품 방향의 기준을 통일.
- `src/beardedSurvivorV190.js`: 무전기·식량·물통은 오른손 소켓, 그릇은 왼손 소켓에 부착. 기타는 양손 동작을 고려해 몸통에 배치.
- `src/characterMotionPlanV190.js`: 무전·식사·식수의 X/Z 팔 회전을 각각 보정. 도구를 입 앞에 가져오는 방향 변경.
- `tests/hand-socket-v370.test.mjs`: GLB 본 바인드 회전, 손목 소켓 연결, 손이 얼굴 앞에 도달하는 수치 회귀 검사. 과거 테스트 2개도 새 구조에 맞춰 갱신.
- 독립 실행형 `dist/src`에 동일한 모듈 복사.

## 기술적 한계
현재 캐릭터 GLB는 손가락/손목/팔꿈치 본이 없는 **9관절 리깅**입니다. 도구가 팔 끝을 따라 움직이는 문제는 수정했지만 손가락을 구부려 쥐는 정밀한 그립 애니메이션까지 구현한 것은 아닙니다. 이 부분은 본 추가 또는 리깅 재제작이 필요합니다.
