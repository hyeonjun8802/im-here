# AFTERDAY v4.4 — 무전 너머의 동행자: 구조할 것인가?

> 2026-11-04 · AFTERDAY_ITEM_DISCOVERY_SCENARIO.md의 다음 에피소드

**극적 질문:** “구조 요청을 받은 순간, 주인공은 식량보다 소중한 것을 얻을 수 있다. 그러나 두 사람의 생존을 감당할 수 있을까?”

## 1. 미완성 구조 신호를 실제 게임 선택으로

v4.3까지 무전기의 32% 결과는 ‘타 생존자 교신’ 로그만 남았고 캠프에 합류하지 않았다. 이번 변경에서는 **다른 생존자의 구조 요청**이 실제로 도착하고, 유저가 **받아들임 / 거절함**을 명시적으로 선택한다.

### 상황창: 계단실의 낯선 목소리

> “들리십니까? 붕괴한 거리에서 살아 나왔습니다. 제발 하루만 쉴 곳을 주세요.”
>
> 옥상에 한 사람의 자리를 더 만들면 물과 식량을 나눠야 한다. 그러나 그는 쓸 만한 정수기나 텃밭이 있다면 손을 보태겠다고 한다.
>
> **[🤝 생존자를 받아들인다]** / **[🛡 생존자 요청을 거절한다]**

**수락:** NPC 지원 생존자 한 명이 옥상에 합류해 보이고, 지속적으로 자원을 먹고 일한다. **게임에서 직접 조작하는 주인공은 계속 한 명**이다.

**거절:** 보급품을 지킨다. 불필요한 체력·자원 패널티가 자동으로 부과되지 않는다. 나중에 다른 무전 교신이 발생하면 다시 선택할 수 있다.

선택창 닫기는 거절이 아니다. 제안이 저장되고 HUD의 **‘생존자 구조 선택’** 버튼으로 무음 재열람할 수 있다. 첫 상황창 알람은 해당 교신마다 **한 번만** 재생한다.

## 2. 첫 무전 이후 3개 분기 — 기획 확률

| 무전 결과 | 확률 | 신규 효과 |
|---|---:|---|
| 🚁 구조 헬기 보급 | **24%** | 기존대로 물·식량·치료제·부품 중 한 종류를 드롭, 중복 지급 없음 |
| 🤝 생존자 신호 | **32%** | 지원 생존자가 아직 없으면 옥상 수락/거절 선택창을 생성 |
| 📻 무응답 | **44%** | 아무 보급품도 얻지 못함 |

무전 시도는 **게임 DAY당 1회**다. 이미 합류한 동료가 있을 경우 같은 공간에 NPC가 무한히 생성되지 않는다. 동료가 한번 건강 악화로 떠났다면 이후에도 무한 재모집하지 않는다.

## 3. 동료의 이득과 대가 (모두 게임 수치)

| 조건 | 수치/효과 |
|---|---|
| 동행 NPC | 최대 1명, 조작 불가 |
| 합류 직후 건강 | 78/100 |
| 식량 소비 | **게임 24시간당 식량 1개** |
| 식수 소비 | **게임 24시간당 식수 1개** |
| 정수기 가동 효율 | 동료가 건강할 때 **+30%** (하루 +2 정수기 생산 한도는 그대로) |
| 텃밭 재배 속도 | 동료가 건강할 때 **+30%** (식량 저장량 16 상한은 그대로) |
| 수리 부품 확보 | 안전한 맑음/흐림 기간 **게임 2일 누적 활동당 약 +1개**, 부품 저장량 14 이상이면 작업 중단 |
| 텐트 없는 비·한파·뇌우 | 동료 건강 서서히 감소 |
| 식량/식수 부족 | 동료 건강이 각각 -9 / -12, 다음 게임 24시간마다 누적 |
| 동료 건강 0 | 동료는 캠프를 떠나며, 더 이상 생산 보조/소모가 발생하지 않음 |

**의도:** 동료는 공짜 생산 설비가 아니다. 정수기·씨앗이 둘 다 없을 때 동료를 받아들이면 오히려 먹을 사람이 늘어 위험해진다. 설비가 준비됐고 식량·식수가 충분할 때 합류시키면 장기 생존 효율이 올라간다.

정수기 자체의 **하루 최대 식수 2개 생산 상한, 폭우 일일 집수 +4 한도, 식량 비축 16 상한은 그대로** 유지된다. 3D NPC는 이미 로딩된 주인공 모델과 애니메이션을 공유해 GPU 자원과 배포 저장소 사용량을 줄인다. 조작 포커스, 카메라, 주인공의 게임오버 로직은 변하지 않는다.

## 4. 서사: 두 개의 그릇

>
> 단파 무전기에서 간헐적인 숨소리가 들렸다.
>
> “먹을 건 없습니다. 하지만 고장 난 정수 필터는 고칠 수 있어요.”
>
> 주인공은 남은 식량 세 개를 본다. 오늘 혼자 먹으면 닷새를 살 수 있을지도 모른다. 누군가와 나누면 내일은 더 위험해질 수 있다.
>
> 하지만 내일 비가 온다면, 두 사람이 함께 고친 정수기로 더 많은 물을 만들 수 있을지도 모른다.
>
> 두 번째 그릇을 내놓을 것인가?

## 5. 상태 저장과 기존 플레이어 보호

- 구버전 저장 키와 버전 4를 유지한다. 신규 동료 상태 필드가 없던 저장은 **동행자 없는 상태**로 안전하게 이관한다.
- 무전 ID로 선택 제안을 식별하고 수락한 사건은 재생되지 않는다.
- 식량·식수 소비는 **실제 게임시계 1분** 단위로 누적한다. 새로고침/프레임률과 무관하게 24시간을 채운 경우에만 각각 1개 소비된다.
- 게임을 종료한 동안 기존 **오프라인 최대 피해 8게임시간 규칙**을 따른다. 동료도 오프라인 동기화 시 동일한 게임 분 계산을 사용한다.
- 사용자가 처음 장비를 하나씩 획득하는 기존 DAY 1~30 장비 개발 흐름을 유지한다. 이미 보유한 영구 아이템, 부서진 배경 도시 건물, 알림 기록은 삭제하지 않는다.

## 6. QA 계약

- 신규 첫날 장비 0개, 탐색 한 번 선택, 이전 저장 캠프 보존.
- 무전 32% 분기에서만 구조 요청. 수락·거절 중복 방지, 새로고침 후에도 같은 결과.
- 새 동료는 **물자 소비가 정확히 1게임일당 1번**, +30% 정수·텃밭 생산, 부품은 소량·저빈도.
- 동료 건강 0이면 3D NPC 숨김 + 자원 생산 지원 종료, 재모집 불가.
- 신규 3D 파일 다운로드 없음. 원래 캐릭터 GLB, 기존 피로/잠자리/토네이도 기능 보존.
- 무전 알림 한 번, 닫은 창의 무음 재열람, 기존 Vercel 중간 배포 없음.

**미검증:** 모바일 기기에서의 체감 프레임률, 실제 이용자의 구조 수락률, 지원 생존자의 실제 장기 난이도. 수치는 사용자 플레이 데이터를 기반으로 한 통계값이 아니라 초도 기획 값이다.


## 2026-11-04 동료 영입 QA 보강 — 단일 알림·최소 비축 조건

- **동일 무전 교신당 경고음 한 번:** 생존자 구조 요청으로 이미 `companion:<radioNewsId>` 알림을 표시했다면, 수락하거나 거절한 뒤 **같은 무전 ID를 일반 `survivorCall` 알림으로 재출력/재재생하지 않는다.** 저장·재접속 후에도 유지된다. 다만 이후 *새로운 교신 ID*는 새로운 한 차례 알림을 가질 수 있다.
- **실제 나눌 음식과 물이 있어야 수락 가능:** 현재 식량 1개 이상 및 식수 1개 이상이어야 영입을 승낙할 수 있다. 부족하면 실패 메시지를 보여주되, 기존 제안은 유지하고 선택창도 닫지 않는다. 거절은 언제나 가능하며, 오늘 필요한 물을 확보해 다시 승낙할 수도 있다.
- **기존 경제 규칙 보존:** 합류 순간 비축량을 임의로 추가 차감하지 않는다. 실제 동료의 식량·식수 소비는 기존 게임 시계 24시간 누적마다 각 1개씩 차감되는 방식이다. 건강이 허락하는 동안 체류하고 물자 부족으로 떠나는 기존 규칙은 그대로다.
