# AFTERDAY v2.6 — 실제 3D 배경 건물 근접화 검증 (2026-11-01)

## 개발 범위

- **사용자 명령:** 배경 건물을 더 가까이. 이전 v2.5의 낮은 높이·폐허 외벽·지면 안개·3D 건물 디테일과 플레이어 옥상은 유지.
- 새 이미지나 배경 그림을 교체하지 않고, 원래 `src/world.js`가 사용하는 **동일한 도시 생성 함수** `src/cityContraction.js`와 `src/cityInfillPlanV150.js`의 거리 띠와 필지 간격만 조정.
- 주인공 옥상은 오직 1개. 배경 건물의 모든 높이는 기존 지붕 상한과 식생 상한 아래. 캐릭터/게임 날짜/날씨/저장 로직 파일 변경 없음.
- 여러 필지 후보를 충돌 확인 후 채택하는 원래의 결정적 배치 정책을 유지. 공간을 더 압축해도 건물이 서로 침범하지 않도록 최종 실제 좌표에 대해 검증.

카메라: 1536×940, 테스트 카메라 FOV 46°, yaw 0.78, pitch 1.29, radius 79. 실제 게임 창은 `resize()`에서 FOV 48°로 재설정할 수 있으므로 **위 화면상 숫자는 엄밀하게 말해 렌더 스크린샷이 아닌 재현 가능한 3D 좌표 투영 검증**임. 실화면의 날씨·안개·재질·FPS는 별도 확인 필요.

## 테스트 및 배포

- `npm test`: **160/160 통과**, v2.6 근접 배치/옥상 안전 반경/시야 추가 테스트 포함.
- `python3 scripts/build_static_release.py`: 최신 `src`와 텍스처로 `dist` 재생성.
- `node scripts/audit_city_camera_v260.mjs`: 카메라 투영 지표 재생성, `docs/qa/v260/camera_projection_audit.json`.
- 이 실행 환경에서 실제 Chromium 캡처 시도 결과 EGL/ANGLE 초기화 실패 및 타임아웃. 실제 렌더 검증 성공으로 주장하지 않음.
- Mac: `RUN_STANDALONE_MAC.command` 실행, 선택적으로 `CAPTURE_GAME_MAC.command`로 Mac의 실제 Chrome에서 촬영 시도 (미검증).
