# AFTERDAY v1.9.3 — 승인 이미지 기반 실제 GLB 재작업

> **검수 결론: 미합격 / 프리미엄 목표 이미지와 동일하지 않음.**
> 이 패키지는 게임 코드에 적용된 실제 3D 모델과 반복 비교 검수물이다. 실제 브라우저 렌더링/모바일 동작은 미실시. 최종 출시 승인이 아니다.

## 고정 기준

- `docs/qa/APPROVED_CHARACTER_TURNAROUND.png` — 사용자가 승인한 유일한 전신 디자인 기준.
- 짙은 갈색 **각진 캡모자**와 부드러운 작은 챙, 검은 머리와 짧은 수염.
- 중년 수염 아저씨 분위기, 큰 머리/몸통에 **짧은 팔다리**, 솟지 않는 어깨, 일관된 올리브색 실용 재킷, 카키색 바지와 가죽 부츠.
- 너무 많은 장비나 각진 조립식 갑옷 금지, 눈·광대·귀 과장 금지.
- 모션: 이동, 의자에 앉기, 식사, 기타 연주, 무전, 걷기. 기존 named rig 9개 보존.

## 이번 v1.9.3 실제 구현

1. `scripts/build_bearded_survivor_v190.py` 수정 및 GLB 재생성.
2. 캐릭터 몸체를 다수의 겹쳐진 공 대신 보다 연속적인 3D 곡면 재킷으로 모델링.
3. 팔과 어깨의 관절 위치 재배치, 손/장갑 가시성 조정. 모션 부품은 기존 게임과 같은 joint 이름 사용.
4. 턱수염은 여러 개의 독립 검은 구체 대신 `marching_cubes`로 생성한 **하나의 곡면 메시**로 교체. 머리·눈·코와 충돌하지 않도록 조정.
5. 승인이미지의 재킷 부분을 **실제 3D UV 표면의 알베도 텍스처**로 투영; 정적인 카드 이미지/빌보드를 사용하지 않음.
6. 재킷·모자·수염·바지·가죽 등 여러 PBR 재질, UV와 법선 텍스처를 실제 GLB 안에 포함.
7. 캡모자의 넓고 납작한 상단 및 얇은 챙, 어깨 낮은 라인, 짧은 팔·다리 구조 유지.
8. 동일한 GLB 파일 경로 `public/assets/models/afterday/afterday_bearded_survivor_v190.glb` 덮어쓰기. 게임은 `GLTFLoader`로 기존 경로를 불러옴.
9. `Head` rig의 Y축 스케일을 0.87로 줄여 머리/몸통 비율 조절. 관절 이름은 유지.
10. 모델 교체와 무관하게 세계·재난·시간 로직은 변경하지 않음.

## 남은 차이 — 숨기지 말 것

- 승인 이미지의 정교한 피부, 눈매, 수염 섬유, 자연스러운 옷 주름/헤어카드와 실제 GLB 사이에 **명백한 품질 차이**가 남아 있음.
- 본 캐릭터는 전문 인체 스컬핑/리토폴로지/스켈레탈 스키닝 작업을 마친 최종 상용 캐릭터가 아님. glTF named-node 관절로 동작.
- 승인 이미지의 착석 자세와 애니메이션의 미세한 무게중심까지 동일하지 않음.
- 게임 실제 화면과 동일하게 렌더링하는 GPU 브라우저 스크린샷은 이 환경에서 획득하지 못함.
- 모바일 GPU FPS 및 애니메이션 클리핑 실시간 검증 전. GLB가 약 23만 삼각형이라 최적화가 필요할 수 있음.

## 출시 전 시각 승인 차단 기준

- 정면·45도·측면·뒤·착석 게임 실행 화면을 실브라우저에서 캡처.
- 2D 기준과 실제 카메라 및 피사체 크기를 맞춰 비교. 캐릭터 표정/옷/장비/어깨/모자가 승인된 실루엣과 다른 경우 **미합격**.
- GLB 로딩·걷기·앉기·기타·무전 중 몸이 뜨거나, 관절 및 의자/소품과 관통하면 **미합격**.
- 부득이하게 모바일에서 LOD 조정할 때는 얼굴과 모자 실루엣을 우선 보존.

이 문서는 출시 완료 보고가 아니라 현재 구현/검수의 정확한 상태 기록이다.
