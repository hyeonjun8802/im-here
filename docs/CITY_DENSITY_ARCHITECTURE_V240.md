# AFTERDAY v2.4 · 도시 밀집 및 건축 디테일 개선

## 범위

2026-11-01 사용자의 최종 요청 중 **건물 간격이 여전히 지나치게 넓음** 및 **실제 건물처럼 보일 만큼 건축 디테일이 부족함**을 직접 해결하기 위해 v2.3 소스에 통합. 참고용 AI 이미지를 실제 게임 배경으로 대체하지 않음.

## 실제 변경 소스

- `src/cityComposition.js`: 기본 원거리 건물의 거리 압축률 `.54 → .34`.
- `src/cityInfillPlanV150.js`: 3개 도시 링을 `r=153–225 / 229–324 / 328–455` 범위로 압축. 안쪽의 건물은 폭을 줄이고 간격과 도로 완충을 조정하여 도시 밀집도 및 각도별 균일성을 확보. 모바일 감소 계수 유지.
- `src/cityArchitecture.js` (신규): 기존 건물 좌표에서 **실제 3D 지오메트리**로 층별 콘크리트 띠, 돌출 발코니, 금속 난간/난간 기둥, 우수 배관, 실외기, 통풍팬, 파손된 옥상 난간 생성. `InstancedMesh` 8개 종류로 batching. 단일 옥상에는 구조물 미적용.
- `src/world.js`: 도시 건물 생성 뒤 건축 디테일 3D 오브젝트 함께 생성. 배경 건물 몸체의 새 텍스처 연결. 밤 발광 지도도 실제 존재하는 기존 경로로 수정.
- `src/cityInfillV150.js`: 배경 보조 건물에 동일한 창문/외벽 4종 반영.
- `public/assets/materials/city/facade_premium_{0..3}.jpg`: 기존 침식된 외벽 재질을 재가공해 지나치게 많은 층/압축된 작은 창문 대신 약 8~9개 층과 실제 건축물에 가까운 창문 비율로 재구성.
- `src/cityReclamation.js`, `src/groundMist.js`: 기존 자연 침식·안개 로직 유지.

건물 footprint도 원점 반경 140의 안전 영역 안쪽으로 들어오지 않도록 유지한다. 외벽 구조물 역시 주인공 옥상보다 낮음을 인스턴스 행렬 검사로 검증했다.

`docs/qa/city_v240_topdown_plan.png`는 플래너가 만든 세계 좌표를 그린 **배치 검증 그림**이다. 실제 게임/WebGL 스크린샷이 아님.

## 검증 및 한계

- Node 자동 테스트 154개 통과. 신규 테스트에서 PC/모바일 각도별 커버리지, 건물 거리·높이·안전 반경, 3D 구조물 생성, draw call type 8개, 실물 인스턴스 상단 높이 검사.
- Mac 실행 스크립트의 ZIP 내 POSIX 실행 권한 755 유지.
- 배포 파일 `dist/`에 동일 소스와 외벽 텍스처 및 Three.js vendor 포함.
- **Chromium WebGL 실제 게임 캡처 불가:** 실행 환경에서 로컬 URL 연결에 대해 `net::ERR_BLOCKED_BY_ADMINISTRATOR`가 발생했다. 실제 GPU 렌더링 품질, 실 FPS 및 기기별 가시성은 테스트되지 않았다. 시각 확인 완료라고 주장하지 않는다.
