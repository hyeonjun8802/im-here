# AFTERDAY v1.8 — 캐릭터 착석·생활 동작 정합성 수정

> **상태: Release Candidate 소스 수정본 / 실제 브라우저 모션 합격 미확인.**
> 이 문서의 PASS는 단위 테스트 결과에 한정한다. 사용자가 제공한 v1.7 스크린샷은 문제의 근거이며, v1.8 실제 WebGL 스크린샷과 혼동하지 않는다.

## 사용자 승인 디자인 및 고정 사항
- 기존 v1.7 VRoid/VRM 캐릭터의 **얼굴·눈·머리 조형을 유지**한다. 얼굴을 도형으로 다시 그리지 않는다.
- 학교 제복처럼 눈에 튀는 의상 재질만 낮은 채도의 올리브/먹색으로 **기존 모델의 재질을 조절**한다. 별도의 머리·얼굴·중복 인체 메시를 생성하지 않는다.
- 수염·모자 캐릭터는 **선택 가능한 미래 대안**이며, 현재 얼굴이 마음에 든다는 사용자 결정에 따라 기본값으로 강제하지 않는다.
- 머리카락 바람 효과는 새로 추가하지 않는다. 바람 제어용 인공 헤어 메시도 생성하지 않는다.
- 주인공 옥상 하나, 폐허 서울·거리 안개·날씨·시각·생존 규칙은 그대로 유지한다.

## 실제 스크린샷으로 확인한 v1.7 결함
1. `의자로 이동해 쉬기 · 이동 중` 표시 상태에서 VRM의 다리가 이미 좌석 부근에 걸쳐 있었음.
2. 의자의 실제 방석 높이와 VRM 골반 높이가 무관하게 계산되어 몸통이 공중에 떠 보임.
3. 캐릭터가 **의자 중심을 목표로 직선 이동**해 등받이·방석에 먼저 겹쳐지는 경로 문제.
4. 동작 종료 시 서기 동작으로 곧바로 전환하여 의자와 교차할 가능성.
5. 여러 얼굴·몸통 부품이 겹치는 기존 절차적 캐릭터 대신 VRM을 쓰고 있어도, 서있는 위치·관절 연출이 맞지 않아 제품 완성도가 떨어짐.

## 수정 내역
### 1. 바닥에 발 정렬
`src/officialVRMAvatarV170.js`에서 단순 GLB 바운딩 박스 최소 Y 값뿐 아니라 VRM의 **실제 좌·우 발목 본 높이**를 조회해 옥상 바닥에 정렬한다. 남성 VRoid 샘플의 좌표계·포즈가 다를 경우에도 바닥 기준으로 교정한다.

### 2. 좌석과 골반 정렬
`src/avatarMotionV180.js`의 월드 좌표 기준:
- 접이식 의자 root: `ROOF_Y + 0.15`
- 좌석 쿠션 상단: `ROOF_Y + 1.06`
- 골반 목표: `좌석 쿠션 상단 + 0.11`
- 골반 위치 보정: `기준 골반 세계 Y ↔ 목표 골반 세계 Y`, 범위 제한 및 시간 기반 보간.

팔·다리 뼈만 회전시키는 옛 로직을 대체한다. VRM 본의 원래 길이·비율을 유지하고 VRM 본에만 회전을 적용한다.

### 3. 모션 단계 분리
`approach (의자 앞 이동) → enter (의자 중심으로 천천히 이동·앉기) → perform (앉기/식사/기타) → exit (일어나 의자 앞까지 이동) → done`.

같은 의자는 `sit`, `guitar`에서 공용으로 사용하고, 식사에는 별도 식탁 의자를 사용한다. 무전기는 서서 수행한다. 비상 대피나 기존 수명·자원 시스템은 변경하지 않는다.

### 4. VRM 본 재사용
`@pixiv/three-vrm`에서 다음 본만 제어: 상체, 머리, 상완·하완, 허벅지·종아리. 정면 얼굴/피부 메시나 눈·코·입은 새로 만들지 않는다. 기존 표정은 VRM의 블렌드셰이프를 사용한다.

### 5. 신체·복장 표현 최소화
기존 VRoid 의상 메시를 재사용하고, 재질 이름이 명확히 의상을 나타내는 경우에만 올리브색·짙은 회색 곱셈 틴트를 적용한다. 머리·얼굴·피부·눈·입은 변형 금지. **원본 모델의 넥타이·제복 실루엣을 완전히 생존복으로 교체하지는 못한다.** 이 작업은 정식 라이선스의 완성된 생존복 아바타로 교체해야 함.

## 검증 방법
- `npm test`: 순수 함수·기존 회귀 145개.
- `npm run download:assets`: Github 도시 모델 + VRoid VRM 바이너리 확보(인터넷 필요).
- `npm run dev`: 실제 데스크톱/모바일 웹 화면 확인.
- 별도 터미널에서 `npm install -D playwright && npx playwright install chromium && npm run qa:motion`.
- 출력: `docs/qa/release_v180_actual_browser/*.png` (실제 WebGL 스크린샷), `results.json`.
- 실패 조건: VRM 로딩 실패, 중복 캐릭터 표시, 렌더 드로우콜 0, 캐릭터 골반과 의자 0.25월드 단위 이상 이격, 발이 지면 아래로 0.16 이상 관통하거나 지면 위로 0.24 이상 부유, 브라우저 JS 오류.
