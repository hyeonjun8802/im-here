# AFTERDAY v6.1 — 가까이 보는 소품의 실제 지오메트리 마감

> 타깃 판매가 ₩56,000 / 유료 설치 게임. 비교작 《프로스트펑크》의 화면 물성·장면 위계만 참고하고 고유 디자인/에셋은 복제하지 않는다.

## 시각적 문제

기존 수납 상자·텃밭 프레임·계단 상부 등은 BoxGeometry의 **반듯한 90° 모서리**여서, PBR 재질과 색 보정만 개선해도 각진 장난감 같은 느낌을 남긴다. 회색 건물의 인식성도 세밀한 반사와 모서리 근처의 반사광에 크게 좌우된다.

## v6.1 기술·아트 수정

- `src/premiumBeveledPropsV610.js`: 3분할 실제 RoundBox 지오메트리. 원래 치수·위치·PBR 재질, 그림자 캐스팅 유지.
- 적용 위치: **텐트 바닥, 소형 나무 수납 상자, 수납 상자 뚜껑, 텃밭 경계 프레임과 흙 표면, 계단 상부/문**, 물탱크 및 화롯불 원형 마감의 세그먼트 수 증가.
- **한 개 옥상만** 고도화한다. 원경 도시 수천 개 박스/건물, 외부 지오메트리, 저장/건물 파괴 정보와 충돌 판정은 변경하지 않는다.
- 모바일에서도 소품이 적어 충분히 관리 가능한 삼각형 증가를 목표로 하지만, 실제 FPS/메모리 검증 전에는 성능이 확인됐다고 말하지 않는다.
- 획득한 장비의 가시성 규칙(아이템 없으면 표시하지 않음), 기존 GLB/씬 계층 구조는 그대로다.

## 품질 검수

1. GLB 소품을 불러온 정상 상태와 로컬 GLB를 불러오지 못한 대체 모델 모두에서 모서리가 더 자연스러운지 3D 카메라 샷으로 확인.
2. 텐트 설치/물탱크/텃밭의 캐릭터 애니메이션과 위치가 어긋나지 않는지 확인.
3. 토네이도 파편과 계단 난간이 겹쳐도 소품의 실루엣이 읽히는지 확인.
4. 기존 FPS와 1% low 프레임시간을 비교. 측정이 없으면 향상 주장 불가.
5. Frostpunk와의 **실제 나란히 이미지 비교는 WebGL 캡처가 성공한 뒤** 수행하고, 이전 장면·참고 장면의 카메라와 시간 차이를 반드시 명시한다.

## 완료 판단

자동 테스트/빌드 통과는 지오메트리 계약을 검증하는 것이다. **완벽한 프리미엄 이미지 수준과 동일하다는 의미가 아니다.** 실제 판매가는 화면 완성도뿐 아니라 설치 패키징·성능·사운드·장기 생존 재미의 품질 게이트를 충족해야 정당화할 수 있다.
