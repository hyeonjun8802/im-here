# AFTERDAY v0.8.0 — 3D 그래픽/날씨 전면 고도화 구현 명세

## 목표와 불변 조건

승인된 콘셉트는 **한 개의 고립된 옥상 + 따뜻한 천막/모닥불 + 먼 폐허 서울 + 자연에 잠식된 도시 + 기상 재난**이다. 플레이 옥상, 주인공 생존자, 실제 날짜, 단독 옥상, 재난 관리/탐험/물/식량/수리 시스템은 보존한다. GitHub의 SimCity 건물은 멀리 있는 도시 리소스 공급원일 뿐 일반 도시 건설 게임으로 바꾸지 않는다.

## 실제 신규 GLB 모델

| 파일 | 모델 수(geometry) | 삼각형 | 크기 | 내용 |
|---|---:|---:|---:|---|
| `afterday_shelter_pbr.glb` | 75 | 10,788 | 약 7MB | 방수 천막 지붕, 세워진 측벽, 텐션 로프, 지지대, 받침대, 침대, 내부 수납, 조명 |
| `afterday_water_tank_pbr.glb` | 48 | 7,652 | 약 2.4MB | 금속 탱크, 강철 프레임, 원형 리브, 배관, 필터, 사다리, 밸브, 수위 게이지 |
| `afterday_storage_pbr.glb` | 50 | 780 | 약 4.6MB | 5개 공급품 상자, 잠금장치, 보강재, 손잡이, 덮개 |

파일 경로: `public/assets/models/afterday/`. 이들은 실제 바이너리 glTF 2.0(GLB)이고, 이미지 디자인 시트가 아니다. Python `trimesh`로 생성한 창작 3D 모델이며 GitHub에서 내려받은 모델로 오인하면 안 된다. 코드에서는 `src/world.js`의 `loadHeroAssets()`가 실제 `GLTFLoader.loadAsync()`로 연결된다. 포맷·기하 범위·UV/PBR 포함 여부는 `docs/HERO_GLB_AUDIT_V080.json`에 있다.

**GitHub 원본 모델:** `dgreenheck/simcity-threejs-clone`의 기존 도시 3D 모델 로더·후보 목록은 유지했다. 원본 83종의 GLB는 ZIP에 넣지 않았고 `npm run download:assets`가 인터넷을 통해 받아야 한다. 외부 모델이 없으면 먼 건물에 폴백 메시가 사용된다.

## 실제 3D 날씨 디렉터 연결

1. `src/weatherDirector.js`: 실제 프레임 경과시간으로 기상 수치를 연속 보간한다. 이 값은 자동 플레이에서 게임 기상 상태와 연결되지만 시연은 실제 날짜/저장값을 변형하지 않는다.
2. `src/advancedWeather.js`: 3D 눈, 빗방울 충돌 물결, 배수, 낙뢰와 섬광, 토네이도 파편을 유지하며 투명 알파 구름을 신규 텍스처로 교체한다.
3. `src/cinematicStage.js`: 시간에 따른 바닥 젖음, 실제 3D 물웅덩이, 화염/연기, 작업등, 식물 배치, 천막 외장 및 캠프 세부 구조를 제어한다.
4. `src/world.js`: 기상 수치에 따라 태양·하늘·그림자·안개·PBR 재질·생존자 행동을 갱신한다. 신규 GLB 천막 메시는 `BufferGeometry` 정점 업데이트로 바람에 반응한다.
5. `src/survivorArt.js`: 우천/한파에서 후드를 표시한다. 실제 인물 애니메이션 수준은 아니다.

## 성능 전략

- 원경 건물은 주인공 옥상에서 멀리만 배치한다. 도시의 폴백은 `InstancedMesh` 창문·단순 실루엣으로 간소화한다.
- 주인공 건물 파사드의 수백 개 세부 창문은 Instancing으로 GPU 그리기 호출을 줄인다.
- 모바일은 비/눈 파티클 수와 그림자 텍스처가 자동으로 줄어든다. 품질 수동 선택은 기존대로 남긴다.
- 2048² 옥상 지도는 넓은 면 하나에만 사용한다. 모든 소품에 반복 적용하지 않는다.
- 진정한 30FPS 목표 충족 여부는 아직 검증되지 않았으며, iOS Safari/Android Chrome에서 실측이 필요하다.

## 승인 전제 / 남아 있는 미완성 영역

* 색과 재질이 실제 승인 이미지와 **100% 시각적 일치한다고 판정할 수 없다**. 현재 실행 환경에는 Three.js·Vite npm 의존성이 다운로드되지 않았고 GPU 렌더링 검증도 수행하지 못했다.
* 재질은 오프라인 제작/수치 시뮬레이션 기반이다. 고품질 상용 3D 모델·캐릭터 리깅·AAA VFX를 자동 생성했다는 주장은 하지 않는다.
* 차후에는 실제 GPU 브라우저 캡처를 기준으로 연속적으로 아트 리뷰하고, Blender 수작업 메쉬·스캔 PBR·캐릭터 GLB 등으로 대체하면 된다.

## 실행

```bash
npm install
npm run download:assets
npm test
npm run dev
```

- `http://localhost:5173/?showcase=1`: 황혼 조명 시연. 이 시연은 실제 생존 시각을 바꾸지 않는다.
- 일반 접속은 실제 Asia/Seoul 날짜와 세계 시각에 따른 낮·밤을 사용한다.
- 시간/날씨 시연 패널에서 비·폭풍·눈·토네이도 등을 비교한다.
- Python 재빌드 스크립트는 *선택 사항*: GLB와 모든 텍스처는 이미 ZIP 안에 포함되어 있다.
