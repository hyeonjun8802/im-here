사용자가 승인한 `docs/visual-reference/strict_target_v060.png`를 시각 방향의 기준으로 사용한다. **본 문서는 실제 게임 코드에 적용한 작업의 기록이며, 콘셉트 이미지가 게임 화면과 픽셀 단위로 일치한다는 주장이 아니다.**

## 실제 3D와 2D 영역을 명시
- **실제 3D:** 주인공 건물·옥상·바닥·천막·물탱크·생존자·수납·파이프·식물·캠프 설비·태양광·원경 3D 건물·강우·번개·토네이도·조명.
- **원경 전용 아트:** 레퍼런스에서 잘라낸 먼 도시·산·하늘 영역을 360° 원통에 부착하여 깊이 있는 3D 씬의 최후방 마트로 사용. 하늘이 실제 3D 건물 뒤에만 나타나며, 옥상 자체를 이미지로 대체하지 않음.
- **여전히 미완성:** 캐릭터 전문 리깅, 상용 PBR 고품질 GLB 변환, 픽셀 정밀 일치, 서버 시간 권위, 실기기 GPU 렌더링·FPS 측정.

## 재난·시간
`src/simulation.js`는 변경하지 않았다. 원경은 같은 구성에서 dusk/noon/night/storm 사이를 부드럽게 혼합하며, 태양 방향·실제 그림자·비·번개·토네이도는 계속 실제 Three.js 3D 장면으로 갱신한다.

## 시연
- 일반 생존 모드: `http://localhost:5173/` — 실제 한국 시각에 따라 시작.
- **콘셉트 황혼 장면:** `http://localhost:5173/?showcase=1` — 시각효과만 18:12로 시연. 날짜와 생존 규칙·저장값 변경하지 않음.
- 드래그: 360도 회전. 휠·핀치: 확대·축소.

## 현 환경의 검증 범위
`node --check` / `npm test` / 에셋 파일 및 ZIP 무결성 검사 가능. 현재 작업 환경은 GitHub GLB 바이너리 및 npm 레지스트리 외부 접속 불가. WebGL 런타임 실기기 브라우저 캡처는 별도 수행 필요. **검증 전 상용 수준 일치라고 주장하지 않는다.**
