# AFTERDAY v9.3 — 10분 DAY · 기상 전선 · 모래폭풍 (2026-11-05)

## 기본 시간과 저장 정책
- 게임 1일(24 게임시간) = 실제 활성 플레이 10분(1×). 2/4/8/16/32/50× 배속 유지.
- 화면의 DAY는 생성 시점부터 가상 시간 24시간마다 증가한다. 실제 달력 자정과 무관하다.
- 백그라운드·미접속 중 가상 생존 시계는 멈춘다. 기존 DAY, 식량, 건강, 시설, 파괴된 도시 건물은 초기화하지 않는다.
- 기존 구형 저장의 첫 재난 예보는 현재 시점 기준 최대 24게임시간으로 단축해 이관하지만, 새 스케줄로 생성된 미래 예보(3~4일 간격)는 정확히 보존한다.

## 재난은 매일 새로 발생하지 않는다
재난 7종은 7회 이벤트마다 한 번씩 등장한다. 단, **7일마다**가 아니라 **약 24게임일의 한 기후 시나리오**로 진행한다. 이후 구간의 폭염·산불·모래폭풍 배열은 기존 결정적 시드를 사용한다.

|---|---:|---|---|---|

기본 첫 이벤트 DAY 2이며 순번 뒤 다음 재난 간격은 [3,3,4,4,3,3,4]게임일이다. 현재 생존 DAY가 이미 진행 중인 저장에서는 기존 예보를 한 번 유지하고 이후부터 새 간격으로 진행한다.

## 일반 기상 전선과 전조
- 평온한 날씨는 5~12게임시간, 폭염·한파는 약 8~13게임시간, 비는 3.5~6.5게임시간 유지된다. 대형 재난의 실제 강도 최고 구간은 약 0.7~7게임시간이다.
- 추운 날씨에서 바로 폭우/폭염으로, 더운 날씨에서 바로 눈/비로 일반 날씨가 무작위 교체되지 않는다. **구름·맑음의 완충 전환**을 거친다.
- 예정 이벤트 전 6게임시간은 사건 유형에 맞는 전조를 강제한다. 특히 토네이도: 구름(6~4h) → 비(4~2h) → 뇌우(2~0h).
- 미래 경보 아이콘은 충격 전 마지막 24게임시간만 표시하며, 충격 뒤에는 새 일정의 경보가 제자리에서 다시 시작되지 않는다.

## 모래폭풍 시각 구조
1. 기존의 정지한 원통형 먼지 장벽은 폐기하고, **도시를 통과하며 이동하는 두 개의 넓은 3D 모래 전선**을 사용한다.
2. 각 전선의 표면은 공간 노이즈와 높이별 난류로 수축·팽창하며, 황토색과 짙은 갈색이 층으로 구분된다.
3. 지면 근처 모래띠는 바람 방향으로 빠르게 흐르고, 옥상 주변에는 낮고 굵은 **회전 모래기둥**을 GPU 포인트 기반으로 표시한다.
4. 기존 화면 흐림/먼지 구름 투명도를 낮춰 실제 건물과 전선의 거리감이 남도록 한다. 구조물은 깊이 테스트를 적용하고 배경 건물 파괴 상태를 유지한다.
5. 모바일은 모래띠 240, 회전 입자 160, 전선 2장; 데스크톱은 모래띠 660, 회전 입자 420, 전선 2장. 신규 실시간 그림자광 0개.

## 검증 기준
- 시계 기본 10분/일, 백그라운드 정지, 저장 호환성, 7종 재난 배분, 3~4일 간격, 기후 연결성, 위험 경고/피해/복구, 모래폭풍 셰이더 및 모바일 예산을 테스트한다.
- 실제 Three.js GPU 화면의 시점별 입체감과 저사양 모바일 프레임레이트는 실제 브라우저/실기기 캡처로 별도 확인해야 한다.
