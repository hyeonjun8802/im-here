# AFTERDAY v1.2.0 — 캐릭터·일상 공간 프리미엄 아트 패스

> 게임 코드와 실제 로컬 리소스를 수정한 소스 빌드. 캐릭터의 수작업 스켈레탈 GLB 또는 AAA 아트 퀄리티를 검증한 완성품은 아니다.

## 고정 콘셉트

- **플레이 옥상은 오직 하나.** 서울 폐허 도시는 근·중·원경이 있는 별도 3D 공간이고, 다른 플레이 옥상/캠프를 추가하지 않는다.
- 고립된 도시 옥상에서 현실적인 생존자가 식사·대피·수리·기타·무전 등 일상 행동을 자율적으로 한다.
- 인물은 성인 생존자이며 과장된 애니/치비/영웅 장비를 입히지 않는다. 어두운 올리브 재킷, 카고 팬츠, 스카프, 마모된 배낭, 장갑, 부츠의 기존 실루엣을 보존한다.
- 기존 날씨·재난 6종, 실제 날짜와 일몰·안개, 오프라인 생존 정산을 제거하지 않는다.

## 신규 자산

- `jacket_field`, `cargo_trousers`, `backpack_canvas`, `scarf_wool`, `aged_leather`, `boots_rubber`, `hair_fiber`, `weathered_skin`, `scuffed_metal`.
- 모든 재질마다 `[name]_base.jpg`(sRGB), `[name]_normal.jpg`(선형), `[name]_rough.jpg`(선형/그레이스케일) 구분.
- 새 이미지는 **프로시저럴 생성 원본**이며 텍스처 패턴으로 사용하는 것으로, 이미지로 덮은 캐릭터 스프라이트가 아님.
- 재생성 스크립트: `scripts/create_survivor_pbr_v120.py` (필요시 `pip install numpy Pillow`). 원본 텍스처는 ZIP에 포함되어 있으므로 일반 플레이에 Python은 필요하지 않음.
- `docs/V120_CHARACTER_PBR_CONTACT.png`: 텍스처 샘플 확인용; 게임에는 직접 쓰지 않음.

## 조작과 플레이

1. `npm install && npm run download:assets && npm run dev`
2. 브라우저에서 `http://localhost:5173` 실행.
3. **일상 행동 → 인물 디테일 확대**를 선택하면 카메라가 캐릭터를 좁은 거리로 추적함. 회전·확대 가능.
4. 의자·기타·무전 등 원래 v1.1 행동으로 걸어가며 자세가 전환되는지 확인.
5. 날씨 메뉴에서 폭우와 맑음을 전환하며 캐릭터 스카프와 의상 광택 및 기존 대피 로직을 확인.

## 검수 기준과 남은 한계

- ✅ 기존 리깅 계층과 게임 로직을 그대로 사용하므로 옷·장갑·신발 추가 메시가 몸과 함께 움직임.
- ✅ 27개 이미지가 패키지에 포함되고 각 768×768 크기로 테스트함.
- ✅ 별도의 플레이 가능한 옥상이나 장르 변경을 추가하지 않음.
- ⚠️ 캐릭터는 Three.js로 제작한 **관절형 절차적 메시**이지, 수작업 디지털 스컬핑으로 제작한 고품질 스킨드 애니메이션 모델이 아님.
- ⚠️ 새 얼굴·머리·재킷이 레퍼런스 인물과 시각적으로 100% 일치한다고 할 수 없음.
- ⚠️ 개발 컨테이너의 npm 레지스트리 접근 불가 및 Chromium 렌더링 초기화 실패로 빌드·실 GPU 캡처·기기 FPS는 검증하지 못함. Mac에서 별도 확인 필요.
- ⚠️ 상용 아트 수준까지는 전문 리토폴로지·스킨 웨이트·얼굴 리깅·애니메이션 클립과 실제 인게임 캡처 대조 작업이 필요함.
