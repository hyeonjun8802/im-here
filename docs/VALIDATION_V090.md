- 기존 v0.8 + 이번 신규 Node 테스트 모두 실행. **68/68 통과** (2026-10-31 제작 환경).
- `node --check`로 모든 런타임 JS와 Node 스크립트 문법 검사.
- 신규 근경/중경/원경 3D 도시 위치는 순수 함수로 검증. 날짜와 날씨를 바꿔도 같은 위치·높이·회전을 반환함.
- 거리 안개: 먼 건물일수록 수학적 누적 안개가 항상 증가하는지 확인. 맑음/폭우/폭풍 각각 테스트.
- 서울 계절별 태양 고도: 여름·겨울 정오, 아침/자정과 시연 시간 독립성 검증.
- 새 3D 파사드 텍스처 8장과 건물 없는 구름 텍스처 4장 생성·파일 검사.
- 유저가 승인한 5개 날씨별 목표 이미지와 기존 전용 GLB 3종 유지 확인.

## 실행 불가/미검증

- 이 환경은 npm 레지스트리 DNS 오류(EAI_AGAIN)로 `three`와 `vite`를 설치할 수 없습니다. 따라서 `vite build`도 정상 수행할 수 없습니다.
- 브라우저 GPU WebGL 실화면 캡처, 모바일 Safari/Chrome에서 실제 FPS, shader GPU 컴파일은 미검증입니다.
- GitHub 원본 GLB 83종은 바이너리 다운로드가 되지 않아 포함되지 않았습니다. `npm run download:assets` 후 로컬에서 브라우저 검증 필요.
- 신규 날씨 셰이더는 소스 문법 및 의존 결합 기준으로 검토했으나 실제 GPU 픽셀 품질은 검증되지 않았습니다.

이 ZIP은 **실제 게임 코드와 3D 리소스를 수정한 개발 빌드**입니다. 승인된 이미지의 120% 또는 상용 3D 품질을 완성했다고 주장하지 않습니다.
