# AFTERDAY v3.1 — 캐릭터 눕기/기상 관절 모션

## 수정 원인

기존 v3.0의 수면 모션은 캐릭터 전체를 90도로 기울이는 것은 가능하지만, 침대 접근 이후 약 1.45초 동안 캐릭터를 침대 안쪽으로 이동시키는 동작과 실제 앉기/눕기 자세가 분리돼 있었습니다. 앉기 중간 자세도 없고, 기상도 위치와 회전을 단순히 선형 보간하여 침대를 미끄러지듯 통과할 수 있었습니다.

## 수정 구조

- `src/dailyCycle.js`: `sleepAnimation()` 키프레임 경로, 수면 진입 3.8초/기상 4.2초. 순수 계산, 기존 KST 23:00~07:00 일정 유지.
- `src/characterMotionPlanV190.js`: 실제 GLB의 팔과 다리 피벗을 이용해 침대 가장자리에서 무릎 접기/손으로 받치기 → 다리 펴기. 누운 자세와 키프레임 수평 회전 연동.
- `src/survivorLife.js`: 침대 접근 위치 → 가장자리 → 눕는 위치를 관절 자세와 같은 타임라인으로 이동. 기상 때 반대 순서. 기존 화단/침대 경로 충돌 유지.
- `src/beardedSurvivorV190.js`: GLB 그룹의 눕기 회전과 높이를 키프레임 값으로 조절; 수면 중 작은 숨쉬기 표현.
- `character.html` / `src/characterPreviewV190.js`: 실제 GLB와 동일한 침대 크기에서 `침대에 눕기`, `누워 자기`, `침대에서 일어나기`를 독립적으로 확인할 수 있는 QA 뷰.

### 모션 순서

1. 침대 앞 안전 구간으로 걸어서 접근.
2. 침대 가장자리로 접근해 무릎을 구부리고 앉기.
3. 양팔로 몸을 받치며 어깨를 뒤로 내리기.
4. 몸통을 침대 장축(X)으로 돌리고 머리를 베개 쪽에 위치시키며 다리를 펴기.
5. 잠자는 동안 작은 호흡 움직임만 반복.
6. 07:00 또는 수동 명령 시 같은 키프레임을 역순으로 재생해 일어나기.

## 검증 및 한계

- Node.js 테스트 186개 통과 (기존 182개 + 신규 4개).
- 키프레임 왕복 연속성, 앉기 관절 각도, 침대 이동 동기화, 기존 일정·게임 회귀 검사.
- `scripts/build_static_release.py`로 실제 배포 `dist` 갱신.
- Chromium WebGL 로컬 접근이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 실패하여 **실제 게임 렌더링/모션 자연스러움 시각 검수는 미완료**.
- 기존 GLB는 9개 회전 피벗 기반 모델로, 스킨 애니메이션/모션캡처 수준의 사실적 허리·척추 변형이나 침대 매트리스 물리 시뮬레이션은 구현되어 있지 않습니다.
