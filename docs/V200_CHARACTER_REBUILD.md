# AFTERDAY — v2.0 3D 캐릭터 리빌드 보고서

## 요구 및 기존 결함

사용자는 v1.9.3 캐릭터가 승인된 그림과 상당히 다르며 광대/귀/눈/어깨/모자/의상 입체 부품의 과한 조형 때문에 일그러진다고 지적했습니다. 모든 부위를 메시로 묘사하려는 방식 대신, 필요하면 표현을 텍스처(그림)로 전환하고 과도한 디테일은 버릴 것을 요구했습니다. 기존 승인은 **모자 쓴 검은 수염의 성인 남성, 큰 머리와 몸통, 짧은 팔·다리, 절제된 생존복**입니다.

## 적용한 실질적 변경

1. **GLB 처음부터 재제작.** `scripts/build_simple_survivor_v200.py`는 기존 GLB를 편집하는 것이 아니라 새로운 `trimesh.Scene`에서 머리·몸통·캡·팔·다리를 만듭니다. 기존 모델은 `docs/backup/afterday_bearded_survivor_v193_BEFORE.glb`에 보관합니다.
2. **승인 얼굴 텍스처.** `docs/qa/APPROVED_CHARACTER_TURNAROUND.png`의 정면 얼굴을 사용해 눈, 코, 눈썹, 수염을 한 번에 표현합니다. 2D 사진을 화면에 평평하게 고정한 것이 아니라 **움직이는 3D 머리 관절에 종속된 곡면 폴리곤의 UV**에 넣습니다. 옆과 뒷면은 실제 머리 3D와 한 장의 뒤통수 머리카락 셸입니다.
3. **장식 재킷 제거.** 몸통은 하나의 재킷 외형으로 구성하며, 지퍼와 주머니·스카프 디테일은 승인 사진을 입힌 **얇은 곡면 텍스처**로 대체합니다. 어깨 갑옷과 과한 주머니 볼륨을 사용하지 않습니다.
4. **짧은 팔다리 유지.** 연속 소매·바지 형태, 장갑·신발만 개별 3D로 제작합니다. 특히 기존 여러 구체를 쌓은 어깨는 제거했습니다.
5. **기존 게임 호환.** GLB 경로는 의도적으로 `afterday_bearded_survivor_v190.glb`를 유지하며 9개의 피벗 노드 이름은 동일합니다. `GLTFLoader`로 불러와 기존 `BeardedSurvivorV190` 클래스가 그대로 사용합니다. 기존 VRM/모델은 로더에서 숨깁니다.
6. **착석 높이 재검증.** 의자 쿠션에 맞춰 허벅지 굽힘을 조정하고, 서기·착석 시 신발 밑면 위치를 다시 계산했습니다. 기타·식사·무전기 소품은 원래 몸 관절을 계속 따라갑니다.

### 수행한 캡처

`docs/qa/v200/BEFORE_AFTER_MULTIVIEW.jpg`에는 **실제 GLB의** 정면, 45도, 측면, 후면이 동일한 VTK 스튜디오 조명으로 렌더링됩니다. `docs/qa/v200/ACTUAL_GLB_POSES_OFFLINE.jpg`에는 스탠딩, 워킹, 착석, 식사, 기타, 무전 시 관절 위치를 렌더링했습니다. VTK 기반 **오프라인 3D 모델 캡처**이며 Three.js 브라우저 캡처가 아닙니다. 기타·무전·그릇은 게임 실행 시 별도로 부착되는 소품이므로 오프라인 모델 자체의 자세 이미지에는 나타나지 않습니다.

### 눈에 띄는 남은 차이

- 3D 표정 디테일은 전면 사진 UV에 의존하므로 옆면에서 2D가 3D로 이어지는 이음새가 보일 수 있습니다.
- 모자의 천 재질과 재킷 표면은 간접광·그림자에 따라 목표보다 밋밋하게 보일 수 있습니다.
- 보행·착석은 기존 관절 애니메이션이므로 모션 캡처 기반 스켈레탈 애니메이션 수준은 아닙니다.
- 게임 브라우저 WebGL에서 실제 프레임별 시각 검수는 이번 환경에 Three.js/Vite 패키지가 없어 실행하지 못했습니다.

### 금지한 재발 방식

눈알·광대·수염·귀·장식 주머니를 매번 구체로 붙여 문제를 해결하는 식의 입체 부품 증식을 하지 마세요. 모델 교체 시에는 `character.html` 정면과 45도, `pose=sit`에 대한 실브라우저 캡처를 비교한 뒤 승인을 받으세요.
