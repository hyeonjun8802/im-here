# AFTERDAY v1.1 자동·실브라우저 검증 구분

| 항목 | 수행 여부 | 결과 및 범위 |
|---|---|---|
| Node 기반 전체 자동 테스트 | 수행 | `npm test` **85개 통과** (기존 76+신규 9) |
| 새 파일+기존 JS 구문 검사 | 수행 | `node --check` 통과 |
| 신설 텍스처 파일 | 수행 | `jacket_weave.jpg`, `worn_leather.jpg` 존재 및 크기 확인 |
| 경로 알고리즘·활동 목록·재난 대피 | 수행 | 순수 함수 Node 테스트 통과 |
| 기존 생존·날씨 회귀 | 수행 | 기존 테스트 통과 |
| Vite production build | **미수행** | 이 환경은 npm 레지스트리 DNS/네트워크 접근 불가, `three` 및 `vite` 설치 불가 |
| 실제 WebGL 렌더링/스크린샷 | **미검증** | Three.js 의존성 미설치로 플레이 화면 실행 불가능 |
| 모바일 실기기 UI / FPS | **미검증** | Mac/iPhone/Chrome/Safari 기기 테스트 필요 |
| 오리지널 기타·허밍 음향 청취 검사 | **미검증** | Web Audio 런타임은 브라우저에서 사용자 클릭 후 직접 청취 필요 |
| GitHub 83종 GLB 실다운로드 | **미수행** | 다운로드 스크립트를 제공하나 바이너리는 별도 다운로드 필요 |
| 새로운 GLB 완성품으로 교체 | **아니요** | 캐릭터와 악기는 이번 버전에서 오리지널 절차형 3D 메시임. 기존 캠프 시설 3종 GLB는 보존 |

**주의:** 자동 테스트/문법 검사를 GPU 3D 화면 QA로 오인하지 않는다. 상용 그래픽 수준에 도달했다고 아직 말할 수 없다.

## 실행 환경에서 최종 검수

```bash
npm install
npm run download:assets
npm test
npm run dev
```

접속 `http://localhost:5173/?showcase=1`. 하단 `일상 행동`→`🎸 기타·허밍`→`생존자 따라가기` 후 모션/소리/카메라 확인. 같은 방식으로 의자·무전·스트레칭·식사 버튼을 검증하고, 낙뢰/토네이도 시 대피 중단 여부를 체크한다.

기존 `npm run qa:visual`은 Playwright를 별도 설치해야 하는 선택적 실제 브라우저 날씨 화면 캡처 스크립트이며, 이 패키지를 만든 곳에서는 실행되지 않았다.
