# AFTERDAY v0.5.1 — 콘셉트 보존 패치 변경 내역

| 파일 | 주요 변경 |
|---|---|
| `src/artDirection.js` | 실제 사용 가능 원본 3D 모델 화이트리스트, 재질 톤, 금지 미학·시스템 정의 |
| `src/world.js` | 지역·콘셉트 이탈 건물/차량/소품의 실시간 배치를 승인 목록으로 교체. 배경 건물·소품에 바랜 톤 적용 |
| `src/assets.js` | GLB 인스턴스 재질을 복제해 개별 색상 보정이 다른 모델에 누출되지 않게 함. 원본 atlas 텍스처는 유지 |
| `docs/CONCEPT_LOCK.md` | 기획·아트 우선순위, 금지 조건, 3D 시안별 검수 기준 |
| `AGENTS.md` | Codex가 수정 시작 전에 콘셉트 문서를 확인하도록 최우선 지침 추가 |
| `tests/art-direction.test.mjs` | GitHub 모델 존재성 및 금지 모델 참조 방지 5개 테스트 추가 |

## 바꾸지 않은 것

- `src/simulation.js`의 날짜·생존·자원 상태 로직
- 기존 3D 카메라 및 사용자 입력
- 기상 시연과 실제 생존 진행의 분리
- MIT 저작권 고지, 기존 original model manifest 83종

## 정확한 범위

- 이 변경은 **리소스의 선정·배치·일반적 톤 일관성**을 강제합니다.
- 원본 모델의 형상 자체를 상용급 폐허 서울 건물로 자동 개조한 것은 아닙니다. 실제 GLB를 불러오려면 `npm run download:assets`가 필요합니다.
- 실물 GPU 브라우저 렌더링은 이 환경에서 미검증입니다.
- 제대로 된 녹·습기·파손 PBR 표면과 영화 같은 3D 날씨의 최종 퀄리티는 GLB 개조/현장 렌더링 검수가 더 필요합니다.
