# AFTERDAY v0.5.2 — 단독 생존 옥상 공간 배치 수정

## 요구 확정
- 플레이어 루프탑: 1개
- 주변 다른 루프탑/캠프: 0개
- 원경 건물: 실제 GitHub GLB를 멀리 배치
- 카메라: 360° 자유 회전, 어떤 방향도 인접 옥상이 보이지 않도록 설계
- 중앙 160 유닛 비우기, 배경 건물 시작 최소 180 유닛

## 코드 변경
- `src/spatialLayout.js`: 검증 가능한 배치 상수와 원경 배치 함수 생성
- `src/world.js`: 기존 43~104 유닛 인접 빌딩 전부 철수, 180~385 유닛으로 이전; 바닥 잔해·도로·버려진 차량도 원경 이전
- `src/world.js`: 유일한 주인공 타워의 외벽 및 창문 추가. 보이는 측면 건물은 **같은 생존 건물**임
- `src/world.js`: 토네이도 및 원경 낙뢰 위치를 280 유닛 밖으로 변경
- `src/artDirection.js`, `docs/CONCEPT_LOCK.md`, `AGENTS.md`: 이웃 옥상·공중 연결 금지 정책 추가

## 범위 제한
- `src/simulation.js`와 실제 날짜·저장·생존·자원 계산은 변경하지 않음
- 외부 GitHub의 모델 GLB 자체, 라이선스, manifest는 변경하지 않음
- 브라우저 GPU 결과를 직접 캡처해 검증한 상태는 아님
