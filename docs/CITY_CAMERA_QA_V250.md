# AFTERDAY v2.5 — 게임 도시 밀도/건물 외형 개선 및 검증 보고

## 사용자가 요청한 수정 기준

- 실제 게임에서 **전경 옥상 주변부터 건물이 크게 보이도록** 배경 건물 거리를 재조정.
- 넓게 흩어진 박스형 건물 대신 **건물로 읽히는 창·층·발코니·기둥·실외기·옥상 설비·파손·식생** 표현.
- 건물마다 높이·폭·깊이·외벽 종류가 다르게 보이도록 구성. 뾰족한 꼭대기 금지.
- 지면 안개는 지상과 건물 하단을 가리되 가까운 건물 입면까지 하얗게 지우지 않도록 조정.
- 모든 배경 건물 본체와 식생은 **주인공 옥상 y=16 이하**. 단일 생존 옥상 및 생존·날씨·시간·캐릭터 유지.

## 계량 결과

- PC 배경 건물 398개 (기본 건물 160 + 보조 건물 238). 겹친 건물: 검사 기준 **0개**.
- 배치 중심 거리 약 **93.7 ~ 349.4유닛**. 기존 v2.4 약 153~455유닛.
- 건물 본체 높이 약 **13.0 ~ 36.8유닛**, 지면 기준 y=-23.5, 주인공 옥상 y=16.
- 동일한 게임 시작 카메라(1536×940, FOV 46°, yaw .78, pitch 1.29, radius 79)의 Three.js 월드 좌표 투영 결과: 주력 근거리 건물 스크린 공간 중간 높이 **v2.4 약 139px → v2.5 약 250px**. 화면 내 투영된 건물 130개.
- 자동 회귀 검사 **158/158 통과**. 생존, 시간, 날씨, 원본 공간 계획 파일의 SHA는 v2.4와 동일.

> **한계:** 위의 px 결과는 Three.js 카메라의 수학적 투영값으로 **실제 브라우저 스크린샷이 아닙니다**. 현재 작업 환경 Chromium은 localhost, file:, data: 이동까지 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되므로 실제 조명·안개·재질과 프레임 성능은 확인하지 못했습니다. 따라서 콘셉트 이미지와 시각적으로 같다는 최종 판정은 하지 않습니다.
>
> Mac의 `CAPTURE_GAME_MAC.command`는 실제 게임 화면을 Chrome으로 캡처하기 위한 **미검증 보조 스크립트**입니다. `SCREENSHOTS/AFTERDAY_V250_ACTUAL_GAME.png`에 저장하도록 구성했으나 해당 Mac 환경에서 정상 동작하는지 확인이 필요합니다.

## 재현/실행

- `./RUN_STANDALONE_MAC.command`: Node.js로 로컬 웹 실행.
- `./CAPTURE_GAME_MAC.command`: Chrome 설치된 Mac에서 실제 WebGL 게임 화면 캡처 시도.
- `npm test`: 순수 소스 회귀 테스트.
- `node scripts/audit_city_camera_v250.mjs`: 게임 카메라로 실제 3D 월드 좌표를 투영한 JSON 리포트 저장(실제 스크린샷 아님).

이 빌드는 장면의 사진 품질을 검증한 상용 완성품 인증이 아닙니다. 기존 환경 구성에 실질적인 3D 개선을 적용한 개발본입니다.
