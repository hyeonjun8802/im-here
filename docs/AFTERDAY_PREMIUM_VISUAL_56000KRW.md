## 1. 판매가의 의미

목표 판매가는 사용자 확정 **₩56,000 / 설치 구매**다. 무료 모바일 캐주얼 게임처럼 '기능이 있는 데모' 수준으로 출시할 수 없으며, 완성도 높은 화면, 몰입되는 사운드와 상호작용, 내러티브의 여운, 장기간의 안정성을 상품 가치로 설득해야 한다.

《프로스트펑크》는 **품질과 무게감에 대한 비교 기준**이다. 고유한 발전기/빙설 도시/건물 외형·UI·음향·이미지를 그대로 베끼지 않는다. AFTERDAY의 차별점은 **한 명의 생존자가 고립된 서울의 단 한 개 옥상에서 며칠을 버티는 이야기**다.

## 3. v5.0 완료 범위와 검증 기준

**화면 전체 통합 표현:** `src/premiumAtmosphereV500.js`에서 화롯불 광원에 정렬된 교차 볼류메트릭 광속(원본 ShaderMaterial), 깊이 검사되는 GPU 입자(먼지/재), 계절/날씨/밤에 따른 가시성을 구현한다. 모바일은 광속 1개/입자 110개, 데스크톱은 광속 2개/입자 310개로 제한한다. 플레이어 옥상 외 제2 플레이 공간은 추가하지 않는다.

**실제 3D 장면 후처리:** `src/cinematicPostV130.js`, `src/presentationPlanV140.js`를 통해 중간톤 대비·절제된 채도·차가운 음영과 따뜻한 하이라이트 분리를 만든다. 블룸은 조명 하이라이트에서만 일어나고, 심한 필름 노이즈는 피한다. 모바일 기본 경로의 후처리 비활성 상태는 유지한다.

**동적 노출:** `src/world.js`에서 밤/폭풍/햇빛의 대비를 부드럽게 조정하고 과도한 환경광을 낮췄다. 토네이도 인근 번개는 **축소된 카메라 흔들림**으로 전달하며 OS reduced-motion 설정에서는 완전히 사용하지 않는다.

**UI:** 기존 모든 버튼/상태/생존 수치와 행동 이벤트를 보존하고 철제 패널의 시각 질감과 생존 정보 계층을 통일했다.

## 4. 56,000원 판매 전 필수 품질 게이트 (현재 미확인)

1. **실기기 FPS:** 목표는 PC(1080p, 고품질) 60fps 이상, 모바일(중급기, 기본 품질) 30fps 이상. 단, 이 목표치는 현재 측정된 결과가 아니다. 
2. **최대 렌더링 응답 시간:** 날씨 변경/토네이도/헬기 등장/동료 합류 시 99p 프레임 타임과 메모리 증가, GPU 과부하 확인.
3. **장면 기준 샷:** 맑은 낮, 일몰, 밤 화롯불, 폭우, 낙뢰, 한파, 근접 토네이도, 복구 장면 × 오버헤드/생존자 근접/시네마틱 카메라. 어두운 공간/복잡한 배경에서 캐릭터가 식별돼야 한다.
4. **자산 품질:** 3D 모델/텍스처의 맞춤 UV/PBR/LOD와 캐릭터 관절/발 디딤/아이템 착용/그림자/젖음 반응을 샷 단위로 확인. 기존 GLB 품질까지 v5.0으로 완성했다고 표현하지 않는다.
5. **생존 루프:** 새로운 무장비 시작→탐색 선택→장비 획득→식량·식수 생산→재난 대피→동료 선택→DAY30까지 끊김 없음. 실제 사용자 코호트의 5일/30일 생존률과 감정 경험 검증이 필요하다.
6. **사운드와 접근성:** 알림음 사건 1회, 무음 재열람, reduced motion, 모바일 UI 가독성, 시각장애 보조 라벨.
7. **판매 정책:** 앱스토어/PC 플랫폼별 상업 이용 가능한 3D/오디오/폰트 라이선스 확인, 안정적인 설치 파일/업데이트/세이브 백업/크래시 대응 정책 마련. **Vercel 웹 앱은 ₩56,000 유료 '설치 앱' 출시에 필요한 스토어 결제·패키징·배포 요건을 아직 충족한다고 볼 근거가 없다.**

## 5. 다음 단계 우선순위

1. **1순위 — 실제 화면 비교 QA:** 동일 카메라/시간/날씨에서 수정 전/후 캡처를 나란히 놓고 과도한 광속·밝기 손실·구성 불균형 교정.
2. **2순위 — 자산 재제작:** 생존자 의복·손/발/얼굴 표정, 텐트 천막/금속 저장함/도시 외벽의 고해상도 PBR, 재난 흔적(파손·오염·눈/물).
3. **3순위 — 사건 시네마틱:** 아이템 발견/동료 합류/구조 헬기 투하/토네이도 직격을 독립 카메라 쇼트·애니메이션·환경음·선택 행동으로 패키징.
4. **4순위 — 기술 최적화:** 실제 GPU 프레임타임을 기반으로 레벨 오브 디테일/그림자 레인지/포스트프로세스 단계별 성능 프로파일링.
5. **5순위 — 상업 릴리스:** 앱 설치 패키징과 스토어 체크리스트, 법적 사용 권한, QA, 출시 전 사전 체험 평가.

원칙: **자동 테스트·빌드 통과 = 출시 그래픽 품질 달성**이 아니다. 미검증 항목은 완료라고 보고하지 않는다.


## 2026-11-04 후속: v5.1 사건별 카메라 장면 추가

기존 그래픽 v5.0은 시간대·물성을 통합했고, 후속 v5.1은 **플레이어 선택이 실제 세계에 남기는 결과**를 카메라로 강조한다. 신규 시네마틱 10종의 상세 기획·기술 조건과 미검증 사항은 [AFTERDAY_PREMIUM_CINEMATIC_V510.md](AFTERDAY_PREMIUM_CINEMATIC_V510.md)에 정리했다. 사용자의 수동 카메라 조작과 생존 루프를 멈추지 않으며, 별도 음원을 추가하지 않는다. 실제 56,000원 출시 완성도는 실사용 그래픽 검수/자산 재제작 이후에 평가한다.


## 후속 2026-11-04 · v5.2 3D 애니메이션 강화

광원과 카메라만 개선하던 v5.0/5.1에서 **물체가 움직이는 사건 현장**으로 확장한다. 텐트 설치 7.4초, 헬기에서 보급 상자 분리·낙하산 착지(18초 전체), 토네이도 파편의 옥상 바닥 탄성 충돌·생존자 충격 반응을 실제 3D에 추가한다. 정확한 구현·한계·실기기 검증 항목은 [AFTERDAY_PREMIUM_MOTION_V520.md](AFTERDAY_PREMIUM_MOTION_V520.md)에 수록. 새 기술이 56,000원 출시 품질 달성을 입증하지는 않는다.


## 2026-11-04 후속 v6.0 — 밝기·채도·재질 품질 우선

기존 v5.0의 어두운 색 보정을 무조건 유지하지 않는다. 화면 전체를 탈색/어둡게 했던 부분과 데스크톱 composer 저해상도 렌더를 보완했다. 실제 DPR 기반 postprocessing/FXAA, 암부 lift·midtone gain·날씨별 채도, 원본 PBR 맵을 지키는 texture filtering/normal smoothing, 주광·환경광·그림자를 개정한다. **코드 수치와 실제 샷 비교는 다르므로** Frostpunk 레퍼런스 대비 실제 성능/시각 품질 검증 전에는 완성이라고 표기하지 않는다. 상세: [AFTERDAY_VISUAL_COMPARISON_V600.md](AFTERDAY_VISUAL_COMPARISON_V600.md).
