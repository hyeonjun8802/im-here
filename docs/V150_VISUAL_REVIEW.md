# AFTERDAY v1.5 — 시각 품질 재검수 및 코드 수정 명세

> 목적: 실제 사용자 스크린샷의 품질 문제를 근거로 **게임 소스를 수정**하고, 다음번 Mac/Codex 실행 시 실제 WebGL 스크린샷으로 검증할 수 있게 한다.
> **중요**: 현재 환경에서는 Chromium이 `net::ERR_BLOCKED_BY_ADMINISTRATOR`를 반환하여 실제 게임 브라우저 캡처에 실패하였다. PNG 파일 `offline_3d_asset_review_v150.png`는 VTK 오프라인 기하/GLB 검수 결과이고, 실제 Three.js 게임 실행 화면이 아니다.

|---|---|---|---|---|

| P0 | 캐릭터 얼굴의 기괴한 비율/겹친 이목구비 | 기존 생존자 얼굴 + premium detail + performer 3중 코/눈/눈썹 중복 | 중복 얼굴 구조 일부 제거, 눈은 Performer가 단독 소유, 헤어 덩어리 감소 | 실브라우저 확대 확인 필요 |

## 2. 구현 구조

- `src/cityInfillPlanV150.js`: 순수 함수 기반 3D 건물 배치 계획. 안개와 계절이 달라도 좌표 불변. 기존 옥상 주변 반경 140 게임 단위 보존.
- `src/cityInfillV150.js`: 4개 GitHub 도시 외벽 텍스처 / 야간 창문 텍스처를 공용으로 사용하는 `InstancedMesh` 3거리층. 추가 도시 건물 825개(PC) / 329개(모바일). 추가 도시 모델은 모두 실제 3D 메시로, 2D 배경을 옮겨놓은 것이 아님.
- `src/world.js`: 도시 인필 초기화와 게임 시각 루프 연결, 낮은 시네마틱 카메라. 날씨·생존·저장 계산 유지.
- `src/survivorArt.js`, `src/premiumCharacterDetail.js`, `src/performerV140.js`: 부품 곡률 개선과 중복 얼굴 제거. 기존 행동/관절 데이터는 그대로 유지.
- `scripts/refine_roof_v150.py`: 기존 게임 내 PBR 콘크리트 기반 고해상도 텍스처 재생성. 실제 2048×2048 3장.

## 4. 실제 GPU 캡처 및 반복 검수 명령

```bash
npm install
npm run download:assets
npm run dev
# 별도 터미널
npm install -D playwright
npx playwright install chromium
npm run qa:visual-v150
npm run qa:compare-v150
```

`qa:visual-v150`은 새벽, 황혼, 비, 낙뢰, 생존자 확대 5장을 촬영하여 WebGL 컨텍스트·렌더 호출·도시 오브젝트 수 등을 검사한다. 실패 시 캡처 성공을 주장하지 않고 오류로 종료한다.

`qa:compare-v150`은 목표 그림, 실제 v1.4 스크린샷, **실제 v1.5 브라우저 캡처**를 한 화면에 놓는다. 서로 다른 구도/렌더러/촬영 시간이기 때문에 단순 픽셀 SSIM이나 거짓 정확도를 부여하지 않는다.

## 5. 반드시 남겨둘 불합격·기술 부채

- 현재 캐릭터는 전문 3D 아티스트의 스컬핑/리깅이 아닌 절차 생성형. **상용 최상급 캐릭터라고 판정할 수 없음.** 실제 GLB 스켈레탈 캐릭터 교체가 근본 해결책.
- 새 보조 건물은 멀리서 도시 밀도를 형성하는 인스턴스형 재질 모델이다. 근접해서 봤을 때 기존 SimCity GLB나 아티스트 제작 외벽과 동일한 수준의 상세 파괴 모델은 아니다.
- 목표 그림의 영화적 볼류메트릭 안개, 고급 반사, AAA급 피부/머리카락, 실제 SSR은 미구현. 실제 브라우저 캡처가 되기 전 '100% 일치'나 '프리미엄 그래픽 완료'로 보고해서는 안 된다.
- GitHub 원본 도시 GLB 83개는 별도 `npm run download:assets`로 받아야 하며 이 ZIP에는 포함하지 않는다.
- 실제 Mac iOS Safari 30FPS 및 GPU 시각 검증은 미완료. `docs/qa/live-v150/`에 검증 증거가 생성되기 전까지 릴리스 합격으로 처리하지 않는다.
