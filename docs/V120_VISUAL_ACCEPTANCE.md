# AFTERDAY v1.2 — 실제 화면 검수표

## 정확한 비교 절차

1. 개발 서버 실행 후 모바일/PC 모두 3D 옥상이 표시되는지 확인. 콘솔의 WebGL 오류 유무를 기록.
2. 캐릭터 세부 카메라를 열어 **전면·좌측·후면·우측** 네 방향을 촬영.
3. 기존 캐릭터 시트 `docs/visual-reference/SURVIVOR_CHARACTER_ART_DIRECTION.png`를 기준으로 실루엣, 헤어, 의상, 백팩, 신발을 직접 대조.
4. **의자/기타/식사/무전**으로 이동할 때 팔꿈치·무릎·장비가 몸에서 분리되거나 뚫리지 않는지 확인.
5. 맑음·황혼·폭우·한파로 전환하여 의류 텍스처가 사라지지 않는지 확인.
6. 기본 카메라로 돌아가 근·중·원경 안개/건물 고정 좌표가 유지되는지 비교.
7. 모바일 Safari에서 추적 카메라 프레임률·메모리·발열을 측정. 목표 30 FPS이지만 미달 시 원인 기록.

## 허용하지 않는 결과

- 단일 이미지/스프라이트가 캐릭터의 3D 회전을 대신하는 화면
- 인물 장비가 기타/식사/수리 모션 중 떠 있거나 몸을 가로지르는 화면
- 주인공 옥상 이외의 근접 옥상/이웃 캠프
- 도시 건물이 날씨 전환 시 다른 위치로 이동하는 화면
- 실제 날짜와 시연 시간을 혼동하는 화면

**미실시:** 이 패키지 작성 환경에서는 실제 WebGL GPU 스크린샷을 취득하지 못했다. 합격 판정을 임의로 기록하지 않는다.
