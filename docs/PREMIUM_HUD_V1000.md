# AFTERDAY · 프리미엄 HUD v1000 검증 안내

디자인 고정: 딥 사파이어 글래스, 티타늄/구리 테두리, 중앙 재난 이미지, 왼쪽 생존 상태·물자, 오른쪽 24시간 재난 예측만 허용.

- 기존 게임 상태/날씨 로직 불변; `src/main.js`에서 import/초기화/sync 3줄만 추가.
- 이미지 50개: v5 정렬 검수 원본 픽셀 그대로, 중앙 원형/좌우 날개의 **비파괴 레이어**를 별도 생성.
- 타임라인은 게임의 `majorDisasterType`, `majorDisasterAt`를 직접 사용. 예측 불가능한 중간 날씨를 조작해서 채우지 않음.
- PC 2560×1440, 1280×720 / 모바일 390×844, 320×568.
- QA 스크립트는 월드 초기화, 브라우저 리소스 로딩, HUD 높이 20% 이내, 화면 클리핑, 생존 상태값 개수를 검사. 실제 Three.js 게임 스크린샷을 생성하지 못하거나 오류 발생 시 **실패 처리**.
- 통과 시에만 main merge / 배포. feature 브랜치는 미승인 개발본이므로 QA 결과 확인 전 운영에 반영하지 않음.

설치·롤백 스크립트 및 v5 원본 리소스·브라우저 단독 렌더링 테스트는 별도 개발 ZIP에 포함.
