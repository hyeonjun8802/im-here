# AFTERDAY · 검은 지도 12개 탐사 시나리오 (v84)

## 검증된 기획 범위와 이번 구현의 경계

- 기존 탐사 첫 2곳: 무너진 주택, 버려진 편의점. 저장 구조와 일일 탐색 보상은 그대로 유지.
- 원래 합의된 12곳: 근거리 6곳(무너진 주택, 편의점, 폐허 약국, 버려진 화원, 오래된 정수실, 통신실), 원거리 6곳(대형 마트, 지하차도, 병원, 변전소, 공동 대피소, 옥상 헬기장).
- 통신탑 흐름: 발견 → 현장 조사 → 수리 부품 확보 → 복구 → 17번 채널 연결 → 원거리 구역 개방.
- 세부 장소 대사, 해금 순서, 통신탑의 부품 비용 4개 및 결말 기록 UI는 이번 단계에서 기존 생존 경제에 맞춰 작성한 **구현 상세안**이다. 기존 기획에서 확정된 수치나 원문이라고 주장하지 않는다.
- 이번 버전은 **지도·선택지 중심 탐사 캠페인**이다. 모든 거리의 실제 3D 내부, 직접 자유 이동, 헬기 착륙 연출, 실제 구조 성공 엔딩은 이 작업에 포함되지 않는다. 구조 신호 결말은 송신 기록이며 구조를 보장하지 않는다.

## 게임플레이 연결

1. 지도는 근거리/원거리 각 6개의 핀만 표시한다. 미발견 장소는 카드의 실제 지형·상세 정보를 미리 드러내지 않는다.
2. 최초에는 무너진 주택만 발견한 상태이다. 방문 이후 편의점, 다음으로 약국/화원, 정수실, 통신실을 발견한다. 탐사의 위험·소모·선택 규칙은 기존 `resolveScavengeChoice`로 처리한다.
3. 출발 → 도착 → 사건 선택 → 귀환으로 이어지는 실제 게임 시간 25분 단계와 최소 2.4초 현실 시간 제약을 유지한다.
4. 선택지는 장소별 문구를 다르게 작성하되, 내부적으로는 기존 `go/scout/salvage/stay` 네 가지 결정으로 연결한다.
5. `item` 또는 `supplies` 결과만 조사 완료로 기록한다. 부상/감염/빈손은 방문으로 남아 이후 재도전할 수 있고, 자발적 귀환은 방문으로 인정하지 않는다.
6. 통신실 완료 후 통신탑이 발견된다. 통신탑을 조사하고 기존 수리 부품 4개를 한 번만 차감해 확보한 뒤 복구한다. 17번 채널 연결에는 기존 단파 무전기 보유가 필요하다.
7. 17번 채널 연결 후 원거리 여섯 곳의 위치가 발견된다. 모든 장소를 완료하면 정착 또는 구조 신호를 **선택해 기록**할 수 있다. 이 결말은 게임 종료나 보상 증식이 아니라 생존 이야기의 기록이다.

## 리소스 품질과 검증

- 운영 이미지 소스는 기존 약 2~5KB의 원본 WebP가 아닌 1600×900 장소별 상세 SVG와 1536×1024 고밀도 지도 SVG로 변경했다.
- 기존 v2 SVG+WebP는 파일과 해시 검증을 보존하되 운영 UI에서는 사용하지 않는다.
- 모바일 지도는 근거리/원거리 탭과 고해상도 캔버스 안개를 사용한다.
- 높은 `viewBox`/벡터는 **기술적 선명도**에 대한 대책이며 사진 수준의 예술적 완성도 또는 실제 기기 렌더 품질을 보장하지 않는다. 인게임 시각적 검증과 더 높은 품질의 사진·렌더 리소스 채택은 별도 품질 작업이다.
- 기존 저장 키·메인 저장 버전 4, 날짜, 기상, 생존자 상태, 캐릭터 애니메이션, 최초 두 위치의 ID와 완료 규칙은 유지한다.
