> 2026-11-04. ₩56,000 **유료 설치 게임 목표**를 위한 **2차 연출 개선**. 실제 게임 출시 품질을 달성했다고 주장하지 않는다.
> 연관 기준: [AFTERDAY_PREMIUM_VISUAL_56000KRW.md](AFTERDAY_PREMIUM_VISUAL_56000KRW.md), [AFTERDAY_ITEM_DISCOVERY_SCENARIO.md](AFTERDAY_ITEM_DISCOVERY_SCENARIO.md), [AFTERDAY_COMPANION_RESCUE_SCENARIO.md](AFTERDAY_COMPANION_RESCUE_SCENARIO.md).

## 로그라인

**한 번의 선택이 세계를 바꿨다는 사실을, 텍스트가 아닌 실제 카메라와 빛으로 보여준다.**

AFTERDAY는 아직도 **한 개의 옥상·하나의 조작 가능한 주인공·실제 재난과 지속되는 영구 파괴**로 진행된다. 컷신이 선택을 대체해서는 안 된다. 플레이어가 탐색·라디오·생존자 영입을 결정한 뒤에만 카메라가 잠깐 반응한다.

## 컷 연출 계약

- 4.6~9.0초의 짧은 **실시간 3D 장면**. 녹화 영상, 다른 배경 사진, 강제 로딩/페이드 투 블랙, 추가 UI 모달 없음.
- **게임 시간·배속·생존 자원·탐색 결과는 절대 조작하지 않음.** 현재 실제 세션의 FPS 타이밍으로 카메라를 움직이고, 배속 4×에서도 재생 시간은 동일하게 유지한다.
- 카메라는 **기존 플레이어 시점 → 사물·장면 근경 → 원래 시점**으로 부드럽게 보간한다. 원래 yaw/pitch/radius/target 저장값을 건드리지 않으므로 연출 종료 뒤 수동 카메라 조작과 다른 장면 전환이 정상적으로 이어진다.
- 화면 드래그·마우스 휠·카메라 뷰 버튼을 누르는 즉시 연출이 취소된다. 지진 같은 카메라 흔들림을 선호하지 않는 OS '동작 줄이기(reduced motion)' 설정에서는 카메라를 움직이지 않고 문구와 조명만 보여 준다.
- **선택 완료 직후** 시네마틱 시작. 선택지가 떠 있는 동안 카메라는 움직이지 않는다. 같은 로컬 세이브 재접속 시 아이템·구조품 장면을 다시 재생하지 않는다.
- 토네이도는 실제 근접 피해를 기록한 경우에만 컷을 실행한다. 날씨 시연의 토네이도는 기존 3D 재난 효과만 유지하며 생존 자원·시네마틱 발생을 강제하지 않는다.
- 기본 사건 경고 알림과 사용자가 제공한 MP3는 기존 **사건별 1회 정책**을 그대로 따른다. 시네마틱 시스템은 별도 오디오를 추가하지 않는다.
- **우선순위:** 실제 옥상 직격/근접 토네이도 장면이 재생 중이면 평상시 보상 연출이 이를 끊지 않는다. 선택 중 카메라 UI는 언제나 조작 가능.

## 아트 테크니컬 구현

- `src/cinematicMomentV510.js`: 사건 10종과 지속 시간/피사체 좌표/카메라 높이/국부광 컬러 정의, 이벤트 후처리.
- `src/world.js`: 실제 3D 카메라·광원을 연출 중에만 변경, 카메라 조작 시 취소, scene 내 광원 자원 해제.
- `src/main.js`: 오직 **정상적인 액션 성공 시** 탐색 보상/헬기/동료 연출을 시작하고, 시뮬레이션에서 기록된 실제 토네이도 피해가 적용되면 위험 연출 시작.
- `src/style.css`: 영화 자막과 얇은 안내선. 투명 오버레이로 기존 액션·경고·식량 버튼의 터치를 가로채지 않는다.
- 화면 데이터는 임시 메모리 객체에만 보관. **저장 데이터 스키마와 결제/상점/스토리지 사용량에는 변경이 없다.**

## 이 버전이 입증하지 못하는 부분

테스트/빌드가 통과해도 실제 모바일 Safari FPS와 프레임 지연, GPU 메모리 증가, 객체/카메라 사이의 가림, 셰이더 색공간 일관성, 얼굴·모션과 손에 물건 드는 애니메이션의 예술적 완성도는 자동 테스트만으로 보증할 수 없다.

**상용 판매 전** PC/모바일 실장치에서 최소 10종 컷의 카메라/위치 가림을 직접 검수하고, 헬리콥터 로터/텐트 설치/인물 교신의 모션과 소리의 질감을 더 높여야 한다.
