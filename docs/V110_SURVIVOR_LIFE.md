# AFTERDAY v1.1.0 — 생존자 프리미엄 외형·자율 일상·행동 장소·오디오 개발 명세

**기준:** v1.0 Three.js 날씨 시스템 + 기존 1개 생존 옥상. 세계 좌표, 기상 VFX, 건물 거리 안개, 실제 서울 날짜, 자원 규칙은 그대로 보존한다.

## 1. 문제 진단

v1.0의 생존자 모션은 `leftLeg.rotation.x=Math.sin(t)*...`와 팔 왕복만 존재했다. 기본 몸체는 실린더와 박스 중심이었다. 사용자가 식사·식수·휴식을 눌러도 생존자 움직임은 현장과 연동되지 않았고, 의자·무전기·기타는 별도 행동 시스템이 없었다. 따라서 무대가 살아있어 보이지 않았다.

v1.1에서는 정적인 수치변경 + 허공의 걷기를 **직접 장소로 가서 행동하는 3D 연기(생활 시뮬레이션)**로 전환한다. 단, 실제 수작업 3D 리깅 GLB가 아닌 프리미엄 디테일의 절차형 메시·계층 피벗으로 구현하며, 이 한계를 명시한다.

## 2. 구현된 행동

| 행동 | 실제 이동 장소 | 적용하는 모션/소품 | 게임 상태 영향 |
|---|---|---|---|
| 앉기 | 모닥불 옆 접이식 의자 | 좌식 허리·엉덩이 하강, 허벅지/무릎 굽힘, 호흡 | 없음 |
| 식사 | 식사 테이블·의자 | 앉기, 팔꿈치/손 올리기, 먹는 팔 움직임, 비상식량 소품 | 기존 `applyAction('eat')`에서만 식량 감소 |
| 식수 | 물탱크 전면 | 수통 들기, 고개 숙이기, 마시기 | 기존 `applyAction('drink')`에서만 물 감소 |
| 기타·허밍 | 모닥불 옆 의자 | 기타를 무릎에 놓고 양손 프렛/스트럼, 고개·입 표정, 오리지널 합성 멜로디 | 자원 변화 없음 |
| 무전기 | 천막 앞 무전 테이블 | 안테나 장치, 안테나 마이크 든 팔/손, 고개 살짝 기울임, 교신 시도 | 자원 변화 없음 |
| 휴식 | 천막 내 침구 부근 | 앉기, 어깨 힘 빼기, 느린 호흡 | 기존 `applyAction('rest')` |
| 수리 | 캠프 작업대 | 상체 숙이기, 팔·팔꿈치 공구 동작 | 실제 재료 소모는 기존 수리 버튼 |
| 치료 | 대피소 | 손/팔을 몸 앞으로 모으는 응급처치 자세 | 기존 `applyAction('medicine')` |
| 도시 관찰 | 옥상 가장자리 내측 | 정지, 고개 좌우 돌리기, 상태 경계 | 없음 |
| 요리 준비 | 모닥불 안전지점 | 몸 앞으로 숙이기, 팔을 모닥불 쪽으로 보내는 조리 자세 | 임시 연출: 음식 생성/소모 없음 |
| 스트레칭 | 전망 공간 | 양팔 위로 뻗기, 몸통 움직임 | 없음 |
| 긴급 탐색 | 계단실 앞 | 외출 준비 동작 및 이동 | 기존 긴급 탐색 조건이 승인한 경우만 |
| 폭풍 대피 | 천막 | 야외 활동 중단, 빠르게 이동해 대피 | 실제 날씨 규칙과 연동 |

**중요:** 상태 화면의 `음식 1개 소모`는 `simulation.js`의 적용 결과가 유일한 원천이다. 자율 일상 모션 자체가 음식·물을 자동 생성하거나 중복 소비하지 않는다. 기존 시뮬레이션에서 자동 식사/식수가 발생해 이벤트가 바뀌면 해당 시각적 행동을 연동해 보여준다.

## 3. 캐릭터 메시 설계

### 기존과 달라진 부위

- 몸통: 가슴/허리 실루엣이 바뀌는 LatheGeometry + 적층된 재킷 + 이음/단추/포켓/벨트.
- 상체: 실제 별도의 어깨→팔→팔꿈치→손 피벗, 장갑과 손가락 구분, 팔 앞쪽 봉제선 및 패치.
- 하체: 엉덩이, 허벅지, 무릎, 정강이, 밑창, 끈 4단의 부츠. 착석 때 다리 1.19rad, 무릎 1.37rad 목표 값.
- 장비: 어깨 크로스 스트랩, 슬리핑롤, 포켓/금속 버클, 손전등, 물통 장식, 작은 응급 파우치.
- 얼굴: 코, 입, 눈 흰자·동공, 눈꺼풀, 눈썹, 귀, 비대칭 다발형 머리카락, 스카프 주름, 우천 후드.
- 재질: 재킷용 `jacket_weave.jpg`, 가죽/장비용 `worn_leather.jpg` 텍스처(둘 다 이번 패키지에서 생성).
- 오브젝트 실체: 모든 부위는 카메라 360도 회전 가능한 실제 Three.js 3D 지오메트리이며, 인물 초상 PNG/WebP는 HUD 참고용이다.

### 애니메이션 실무 한계

이 모델은 피벗 기반 계층 애니메이션(Procedural Articulated Character)이지 `SkinnedMesh` 모션 캡처나 리깅 GLB가 아니다. 팔꿈치·무릎 회전은 가능하지만 손가락별 그립, 천의 스킨 변형, 발 IK, 자연스러운 얼굴 표정 블렌드셰이프, 사람 목소리 립싱크, 모션 캡처의 감정 연기까지 구현한 상용 캐릭터로 판단하면 안 된다.

상용 목표까지 올리려면 Blender에서 `char_survivor_base.glb`를 만들어 Mixamo 호환 HumanIK 계층으로 리깅하고, 최소 `idle/walk/sit_down/sit_idle/stand_up/eat/drink/guitar_strum/sing/radio/stretch/shelter_run/rest/repair` 클립을 넣어 `AnimationMixer` 및 상태별 블렌딩·Foot IK로 전환한다. 이 버전의 경로·상태·오디오 로직은 그때 그대로 재사용할 수 있다.

## 4. 경로·동작 상태 머신

`src/lifePlan.js`: 활동 ID, 동작 기간, 허용 날씨, 일일 우선순위, 격자 A* 기반 경로 계획을 포함한 순수 JS.

`src/survivorLife.js`: 스테이션 실제 3D 메시, 목표 이동, 회전 보간, 자세 전환, 관절 계층 애니메이션, 수동 명령, 자동 일상, 폭풍 대피를 처리한다.

상태 전환은 아래와 같다.

```text
idle/wander -> approach (옥상의 물건까지 걷기)
            -> enter    (자리에 접근해 자세 전환)
            -> perform  (활동 기간만큼 손/팔/발/머리 동작)
            -> done     (기타 반환, 동작 정리, 이후 자동생활)

storm/tornado -> shelter (기존 동작 중단, 천막으로 빠르게 이동)
```

시간대 별 기본 선호는 아침(전망·스트레칭·교신), 오전(정비·교신·요리), 낮(의자·요리·기타), 오후(전망·기타), 저녁(모닥불 기타·교신), 야간(천막 휴식)이다. `game.actionUntil`와 무관한 일상 연출 시간을 사용하며 서울 실제 시각은 읽기만 한다. 날짜를 가속하지 않는다.

### 경로와 충돌

옥상 범위 ±20 안에서 격자 경로를 계산하며 불자리, 물탱크 본체, 계단실을 장애물로 회피한다. 기존에 존재하던 모든 소품의 물리 메시와 정밀 충돌하는 NavMesh는 아니며 후속 작업이다. `planRooftopPath`가 유효 경로를 못 찾으면 목표까지의 단순 경로를 반환하는 폴백이 존재한다.

## 5. 통기타·허밍·무전 사운드

- 통기타는 독자 제작한 입체 바디/넥/브리지/프렛/줄·조율 장치를 가진 3D 소품. 연주하지 않을 때는 의자 옆에 기대 있고, 연주 중에는 생존자의 품에 붙는다.
- `src/campMusic.js`는 외부 저작권 음원을 사용하지 않고 오리지널 8음 선율을 생성한다. 기타형 플럭은 삼각파의 짧은 감쇠, 허밍은 기본 사인파+낮은 배음으로 합성한다. **실제 사람이 부르는 노랫말이나 음성 파일을 생성한 것은 아니다.**
- 브라우저 자동재생 제한을 존중해 클릭 전까지 완전 무음. 음악 토글을 켜거나 기타 버튼을 직접 눌러야 `AudioContext.resume()`을 호출한다.
- 무전기는 무전기 외형·안테나가 있는 3D 오브젝트이며, 소리 활성화 상태에서는 짧은 비프음을 생성한다. 현실 통신망 연결·실제 대화·음성 합성 기능은 없다.

## 6. UI·카메라

- 기존 식수/식사/수리/휴식/치료/탐험과 날씨 시연은 그대로 유지한다.
- `일상 행동` 패널에는 의자, 기타, 무전, 요리, 스트레칭, 전망, 천막 휴식, 장비 정비 버튼이 있다. 각 버튼은 월드 좌표에 명령을 내려 실제 위치까지 걸어가게 한다.
- 기타 의자와 식탁, 무전기 메시에 직접 탭하면 해당 연출이 시작된다. 식사는 실제 식량이 감소하는 별도 하단 `식사` 버튼으로 소비를 확정한다.
- `생존자 따라가기`: 기존의 옥상+도시 전경 카메라를 보존하고, 선택 시 radius 26 근처로 전환해 살아 있는 관절 모션을 관찰한다. 이동 중에는 카메라 타깃만 부드럽게 따라간다.
- 패널의 캐릭터 초상 `survivor_portrait_reference.webp`는 기존 디자인 시트를 크롭한 참고 이미지. 이와 실제 메쉬의 외형·얼굴이 100% 일치한다는 뜻이 아니다.

## 7. 기존 월드 보호

- 유일한 옥상 하나; 주변 추가 옥상·연결 통로·마을 없음.
- 도시 원경 3거리 레이어, 날씨마다 동일한 3D 건물 좌표, 거리 안개, 눈·비·번개·토네이도, 일조/실제 날짜 그대로.
- 새로운 외부 유료 3D 모델, 음악, API 호출 없음.
- 기존 저장키 및 플레이어 자원 구조 변경 없음.

## 8. 실제 검수 결과와 후속 고도화

`npm test`를 통해 레거시 76개 + 신규 9개, 합계 **85개 자동 테스트**를 통과했다. JS 문법 검사도 전 파일 통과했다. **실제 GPU 렌더링, 팔/다리 관절 움직임의 3D 픽셀 영상, iPhone Safari 프레임 성능 및 사용자 콘셉트와의 시각 일치도는 검증하지 못했다.** npm 패키지 설치가 이 실행 환경의 네트워크 차단으로 실패했기 때문이다.

게임을 Mac에서 실행한 뒤 반드시 다음 장면을 직접 캡처하여 비교해야 한다: ① 의자 앉은 정면 ② 기타 연주 근접 ③ 식탁 식사 ④ 물탱크 식수 ⑤ 무전기 교신 ⑥ 폭우 도중 천막 대피 ⑦ 밤 모닥불 기타 연주 ⑧ 모바일 Safari 클로즈업. 검수 후 제일 문제인 부분부터 실제 GLB 모션·리깅으로 대체한다.
